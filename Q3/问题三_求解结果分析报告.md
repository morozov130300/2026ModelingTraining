## 二、建模步骤与过程（完整复现路径）

### 2.1 问题定位与信息边界

微网含小区负载 L、光伏 G、储能（E∈[1200,10800] kWh，P_ch=P_dis≤5000 kW，η^ch=η^dis=0.9，日初日末 6000 kWh），不允许向电网售电、允许弃光；紧急购电按交易时刻电价的 **5 倍**结算；购电调整按题目口径：上调 1.5 倍、下调（违约）0.5 倍。

MPC 时间结构：0:00 制定基准计划 Q^(0)；6:00/12:00/18:00 各获一次"未来 24 小时整点光伏预报"，可对剩余时段 T_k=[τ_k+1,144]（τ=36/72/108）滚动重优化；执行区间 B_0..B_3 各 6 小时，已执行时段冻结。已确认的建模决策：

1. **负载口径**：附件3无负载预报，各方案对称使用附件2当天实际负载 L_{d,t} 作为"已知曲线"（公平可比）；
2. **光伏预报口径**：附件3"预报h小时"解释为发布时刻起第 h 个整点瞬时值；10 分钟时段 j 取该时段中点 10j+5 分钟处线性插值 Ĝ_j=(1−f)P_h+fP_{h+1}；发布时刻锚点取"时刻前一槽实际值"（0:00 用昨日 24:00 实际，6/12/18:00 用当天第 36/72/108 列）；夜间负预报值截断 0；
3. **结算口径**：增量结算——C^total = C^plan + Σ_采纳(1.5cU−0.5cW) + 5cR^real（下调退回原购电费、只付 0.5 倍违约费，净 −0.5cW）；
4. **求解方法**：MILP 主模型（保留充放电互斥二元 u，文档§12），k=0 追加 LP 松弛互斥检验 + 词典序二阶段（C*+ε 下最小化 Σ(C+D)Δt，同 Q2）；
5. **采纳判据**（文档§10 第18条）：J_adapt < J_frozen 才调整，否则冻结沿用上一版（购电与储能计划均不变）。

### 2.2 0:00 基准计划模型（文档§5，k=0）

对 144 个时段的决策变量：Q（计划购电）、P_use（购电使用）、S（未使用）、R̂（预测紧急购电）、P_v（光伏利用）、K（弃光）、C/D（充放电）、E（145 点 SOC）、u（互斥二元）：

```
min  Σ_{t=1}^{144} (c_t Q_t + 5 c_t R̂_t) Δt                                  (M1)
P_use + R̂ + P_v + D = L_t + C_t   （功率平衡，Ĝ 为 0:00 预报）
P_use + S = Q                （计划购电分解）
P_v + K = Ĝ_k,t             （光伏分解，允许弃光）
E_{t+1} = E_t + 0.9 C_t Δt − D_t Δt/0.9        E_1 = E_145 = 6000
1200 ≤ E_t ≤ 10800,  0 ≤ C_t,D_t ≤ 5000,  C ≤ 5000u, D ≤ 5000(1−u), u∈{0,1}
```

求解顺序（词典序二阶段，同 Q2）：① MILP 求 C*；② 加约束 (M1)≤C*+ε（ε=1e-6·C*）再最小化 Σ(C+D)Δt，消除 C/D 无成本导致的退化循环。代表日验证：终解费用超 C* 不超过 0.04 元（3-20：40958.0192 vs C*=40957.9782），LP 松弛相对差 3.6e-16、互斥 max min(C,D)=0。

### 2.3 第 k 次（k=1,2,3）滚动调整模型（文档§6/7）

对 T_k=[τ_k,144) 的局部变量，相对上一版 Q^(k−1)、C^(k−1)、D^(k−1) 引入上调/下调 U、W：

```
min  Σ_{t∈T_k} (1.5 c_t U_t + 0.5 c_t W_t + 5 c_t R_t) Δt                    (M2)
U ≥ Q − Q^(k−1) ,  W ≥ Q^(k−1) − Q ,  U,W ≥ 0        （正系数保证 U,W 取精确正部且问题有界）
功率平衡/购电分解/光伏分解 同上，Ĝ 换为 k 时刻发布的预报插值曲线
E_{τ_k+1} = E^real_{τ_k+1}（当前实际储能，由 B_0..B_{k−1} 执行轨迹算出）,  E_145 = 6000
```

**不调购电对照（解析式，无需建模）**：

```
R^frz_t = max(0, L_t + C^(k−1)_t − D^(k−1)_t − Q^(k−1)_t − Ĝ_{k,t})
J_frozen = Σ_{t∈T_k} 5 c_t R^frz_t Δt
```

**采纳判定**：`J_opt < J_frozen` → 采纳（版本 k 生效至 24:00）；否则冻结（沿用上一版 C/D 继续执行）。全年 334 天：6:00 采纳 321 天（96.1%）、12:00 采纳 270 天（80.8%）、18:00 采纳 121 天（36.2%）。

### 2.4 实际执行与紧急购电（文档§8，B_k 区间）

B_k 区间使用"该区间最终生效版本"的 Q/C/D，按附件2实际 L、G 逐时段结算（信息边界：实际值仅在计划锁定后读取）：

```
rd = L + C − D;  R^real = [max(rd,0) − G − Q]^+        （紧急购电，5 倍电价结算）
过放电截断：rd<0 时 D_eff = L + C（未执行放电留在电池内，顺延次日）
E 轨迹：E_{t+1} = E_t + 0.9 C Δt − D_eff Δt/0.9
```

### 2.5 费用汇总（文档§9，增量结算口径）

```
C^plan = Σ c_t Q^(0)_t Δt
C^adj  = Σ_{k:采纳} Σ_{t∈T_k} (1.5 c_t U_t − 0.5 c_t W_t) Δt
C^emg  = Σ_t 5 c_t R^real_t Δt
C^total = C^plan + C^adj + C^emg
```

### 2.6 对照实验（文档§11）与求解流程

- 四组方案：S_0={0:00}、S_1={0:00,6:00}、S_2={0:00,6:00,12:00}、S_3={全4时刻}；各方案 334 天独立回测。
- 工程上：每天只需解 1 个 k=0 + 3 个 k≥1 子问题（采纳判定与 E^real 沿 S3 主路径唯一），各 S_j 由版本链切片模拟得到（确定性，与串行逐日一致）；按天分派 8 进程并行，断点续跑缓存 `Q3/cache/day_*.pkl`（334 个，已生成）。
- 求解规模：k=0 为 1441 变量/144 二元 MILP；k=1/2/3 为 1297/865/433 变量。单日求解调用共 6 次（k=0：一阶段 MILP + 词典序二阶段 MILP + LP 松弛；k=1/2/3：各 1 次滚动 MILP），实测单日 0.3–1.1 s，全量 334 天 8 核并行 34 s。

### 3.4 特殊现象与机理解释（写论文时可直接引用的三个讨论点）

1. **W≡0（全样本下调量为 0）**：k≥1 模型目标为文档§6第一式 1.5cU+0.5cW+5cR（违约口径），下调 W 在该目标中只产生"代价"（+0.5cW）而无"收益"——降低购电只会推高 R̂ 或依赖免费的储能重排，因此最优解恒取 W*=0。这体现文档两种结算口径的分层设计：**模型按违约口径优化（保守、有界），报告按增量口径结算**；若将目标改为增量口径 1.5cU−0.5cW，则 W 无上界会使问题无界（HiGHS 报 status 4），必须额外引入 W 上界约束才可行——这也是本项目实现中实际踩到并修复的问题（缓存版本 q3-mpc-v1→v2 即此变更）。
2. **日尺度 S0..S3 非单调、年尺度单调**：如 3-20 当天 S1(57,899.15)>S0(50,222.19)、9-23 的 S2(45,358.57)>S1(43,606.08)。原因是"采纳"基于**预测**比较（Jopt vs Jfrz），而费用兑现基于**实际** L/G：预测修订方向的采纳在个别天会加剧实际偏差。典型如 3-20：6:00 采纳后 S1 紧急电量 3768.55 kWh 反而比 S0 的 2295.58 kWh 多出 1473 kWh（当日 8:10–9:20 三个连续段），而 S2 在 12:00 再修正后才把紧急电量拉回 1562.05 kWh（低于 S0）。年尺度 334 天聚合后此类单日反差不利因素被平均掉，ΔC_6/ΔC_12/ΔC_18 全部为正。
3. **零成本边界采纳（Jopt=Jfrz≈0）**：如 12-21 18:00，当剩余时段预测供需平衡充裕（R̂=R^frz≈0）且 U=W=0 可行时，两方案费用同为 0（浮点微小差异触发严格 `<` 判定），采纳与否对费用影响 0.0000 元，仅版本指针不同；S3 结果与 S2 相同的 180 余天大多属此类或 18:00 冻结。

## 四、对照实验结论：是否需要引入 6:00/12:00/18:00 预报

> 题目问题："请分析是否需要引入其他时刻的预报制定调整购电策略。"

| 结论 | 依据 |
|---|---|
| **6:00 预报必须引入** | ΔC_6=510,653.90 元（占 S0 总费用 3.41%），紧急电量 −39.4%；6:00 时刻 321/334 天触发调整，是全年最大的误差修正窗口（0:00 预报的 6 小时 MAE 偏差在 6:00 被直接纠正） |
| **12:00 预报建议引入** | ΔC_12=354,284.98 元（占 2.36%），紧急电量再 −29.0%；采纳 270 天（80.8%），覆盖 6:00–12:00 段新累积的偏差 |
| **18:00 预报边际收益很小但仍为正** | ΔC_18=2,944.23 元（仅 0.02%），紧急电量再 −0.23%；采纳 121 天（36.2%）。若交易/计算成本不可忽略，可只保留 6:00+12:00 两次调整（S2），代价是少省 0.29 万元/年（0.02%） |
| 综合 | 建议论文表述：**"引入 6:00 与 12:00 预报有显著净收益（合计 86.49 万元/年，约 −5.8%），18:00 预报收益趋近于零（0.29 万元/年），保留与否取决于交易成本"**。三个边际 ΔC 均 >0，不出现"多一次预报反而更贵"的情形 |

## 五、策略行为解读

1. **主形态延续"谷充峰放 + 光伏优先"**：以 2-01 为例，0:00–4:00 充电 2968.65 kWh（谷价 0.42 元段），4:00–8:00 放电 6603.54 kWh，20:00–24:00 充电 5333.33 kWh（再充一次迎次峰）；全年充电 68.57 万 kWh、放电 55.54 万 kWh（S3 交付口径）。
2. **日内调整的主要动作是"上调"而非"下调"**（W≡0）：6:00 预报一旦下修光伏或上修负载缺口，模型上调 Q（1.5 倍价）并配合储能重排来消除 5 倍价的紧急购电——"付 1.5 倍的 1 元，省 5 倍的 N 元"。
3. **紧急购电被日内修正压到"小额高频"**：S3 全年 1858 个紧急段、平均 149.8 kWh/段（如 2-01 的 6:00–6:50 段 104.89 kWh），全部集中在光伏预报低估或负载上翘的窗口；S0→S3 段数从密集转稀疏、单段规模变小。
4. **信息价值递减**：ΔC_6>ΔC_12≫ΔC_18，与"预报时效越短误差越小"的机理一致；18:00 剩余窗口仅 6 小时，且傍晚负载/光伏波动窗口短，故边际趋零。
5. **日末储电精确回到 6000**（4 代表日 E^real_145=6000.0000）：最后一块（18:00 后 36 槽）无过放电截断且无紧急，执行轨迹=计划轨迹，而计划强制 E_145=6000，属正常现象而非巧合；有截断的日子 E^real_145 会略偏离 6000（顺延次日，同 Q2 先例）。
