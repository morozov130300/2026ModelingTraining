## 二、建模过程与步骤（完整复现路径）

### 2.1 问题定位与信息边界（思路文档 §1、§2.2）

- 每天 144 个十分钟时段，Δt=1/6 h；分时电价每天重复（附件 1）；不向外网售电、允许弃光；计划购电量按计划全额结算（未取用部分照付）；紧急购电按交易时刻电价的 **5 倍**结算。
- **核心边界**：0:00 制定计划时，只能使用日期严格早于 d 的历史数据。附件 2 中当天曲线在计划锁定前必须"隐藏"，锁定后才逐时段揭示用于回测结算。
- 反证依据（文档 §2.2）：若当天实际曲线泄漏进优化器且购电无容量上限，则最优解中紧急购电必为 0（任何 R>0 都可用"计划多买 ε、紧急少买 ε"的替换把费用降低 4c·ε·Δt）。本回测中 93.41% 的天发生紧急购电，侧面印证无信息泄漏。

### 2.2 数据整理（文档 §2.1）

- 附件 1：144 时段电价 c_t（元/kWh），日内曲线每日重复。
- 附件 2：`小区负载`、`光伏发电实际功率` 两张 365×144 宽表，无缺失、无负值、日期连续；时间列按"时段终点"口径（0:10 = 00:00–00:10 时段）。
- 储能参数（附录 1）：容量边界 [1200, 10800] kWh，充/放功率 ≤5000 kW，η^ch=η^dis=0.9，日初日末 SOC=6000 kWh；P_buy,max 题目未给出，取 ∞（不擅自设 5000）。

### 2.3 日前点预测（文档 §3.2–3.3）

**光伏**（逐时段向量化）：对每个时段 t，用最近 K_G=14 天构造指数加权水平项 G̃ 与指数加权局部线性趋势外推 â，按 β 收缩后截断非负：

- 权重 w_k = ρ_G^(k-1) / Σ，ρ_G=0.9，k=1 为前一日；
- 加权 WLS 拟合 y=a−b·k，a 即外推到决策日 d 的水平；
- Ĝ = max{0, (1−β)·G̃ + β·â}，β=0.5。

**负载**：同星期指数加权，K_L=4、ρ_L=0.8，L̂ = Σ w_k L_{d-7k}；引入 2025 年法定节假日与调休日历——节假日优先从此前节假日选样（不足补相似休息日），调休上班日取最近 4 个正常工作日。

### 2.4 负载–光伏联合误差场景（文档 §3.4）

- 对每个可用历史日 h（h ≥ 2025-01-29，负载同星期与光伏 K_G 均可完整因果预测）生成**只用 h 之前数据**的因果预测，得整日残差轨迹 ε^L_h、ε^G_h（成对保留日内相关性与负载–光伏相关性）。
- 场景集 Ω_d：最近 M=20 个误差日，等概率 p_ω=1/20；L^ω = max{0, L̂+ε^L}，G^ω = max{0, Ĝ+ε^G}。
- **暖启动**：误差日不足 20 天时（2025-02-01～02-17 共 17 天），改用"最近 20 个实际日 − 逐时段均值"的均值残差，保证 2 月上半月不跳过、且只用 1 月历史。

### 2.5 两阶段随机 MILP（文档 §4–5）

第一阶段（日前，全部场景共享）：计划购电 B_t、计划充电 C_t、计划放电 D_t、SOC E_t、互斥二元 u_t；
第二阶段（各场景 ω 实时）：紧急购电 R^ω、实际取用 B_use^ω、未取用 S^ω、光伏利用 V^ω、弃光 K^ω。

目标函数（期望费用最小）：

```
min  Σ_t c_t·B_t·Δt  +  Σ_ω p_ω · Σ_t 5·c_t·R^ω_t·Δt          (1)
```

约束：

```
0 ≤ B_t ≤ P_buy,max                                        (2)
0 ≤ C_t ≤ 5000·u_t ,  0 ≤ D_t ≤ 5000·(1−u_t),  u_t∈{0,1}    (3)
E_{t+1} = E_t + 0.9·C_t·Δt − D_t·Δt/0.9                    (4)
1200 ≤ E_t ≤ 10800                                          (5)
E_1 = E_145 = 6000                                          (6)
B_use^ω + R^ω + V^ω + D_t = L^ω_t + C_t                    (7)
B_use^ω + S^ω = B_t                                        (8)
V^ω + K^ω = G^ω_t                                          (9)
R^ω, B_use^ω, S^ω, V^ω, K^ω ≥ 0                            (10)
```

单日规模约 1.5 万变量（含 144 个二元），HiGHS 分支切割直接求解。

### 2.6 求解顺序（文档 §8 + 词典序第二阶段）

1. 求解 MILP 得最优期望费用 C*（mip_rel_gap=1e-9）；
2. 求 LP 松弛（去掉 u_t），检验充放电互斥与费用一致性 → 本实例 334/334 天 LP 有效；
3. **词典序第二阶段**：在 C ≤ C*+ε 约束下最小化储能吞吐量 Σ(C+D)·Δt，消除同费用解中的无意义充放循环（ε=1e-6·C*，对日费用影响 <0.1 元）。

### 2.7 逐日滚动回测（文档 §7）

对每个决策日 d：① 提取历史集 H_d → ② 生成点预测与联合场景 → ③ 求解并**锁定** B/C/D/E → ④ 锁定后才读取当天实际负载/光伏 → ⑤ 紧急购电闭式结算 R = [L+C−D−G−B]^+（光伏优先消纳分摊 S 与 K）→ ⑥ 实际费用 C_d = Σc_t·B_t·Δt + Σ5c_t·R·Δt　(13) → ⑦ 当天数据入历史，进入次日。334 天全部按此逻辑滚动（计算上按天并行，天与天之间数据独立、结果与串行逐位一致）。

## 四、策略行为解读

1. **"谷充峰放"是全年主形态**：所有代表日 0:00–4:00 以 4500 kW 满功率充电（SOC 至 10800 上限），傍晚 18:00–20:00 高价时段放电，直接利用 0.43 vs 1.30 元/kWh 的价差套利。
2. **计划量落在净需求约 80% 分位**（文档 §3.5 的最优分位数机理）：五倍惩罚下模型系统性多买（未取用 8.08%、弃光 10.29% 都是这一保守性的体现），以少量计划费对冲大额紧急费，方向正确。
3. **紧急购电是"误差的兑现"而非"策略失误"**：93.41% 的天发生小额紧急购电（中位数远低于均值），本质是日前预测误差的尾部；零紧急的 22 天集中在春节深度假日与 9 月初晴好期。
4. **9-23 为典型"低估日"**：实际负载全天高于全部 20 个场景（负载 MAE 151 kW、紧急 18 段），储能救不回整日缺口 → 紧急费 1.43 万元。此类日正是问题三引入 6:00/12:00/18:00 日内调整的动机。
5. **6-21 为典型"高估日"**：周末+光伏强（弃光 1.92 万 kWh），计划偏保守但方向安全 → 紧急购电为 0；5 个过放电时段实际"少放即可"，未执行放电 124.19 kWh 留存电池，费用零影响。

## 五、风险集中现象与归因（重要发现）

紧急费 Top8 全部为法定节假日，且高度集中：

| 日期 | 节假日 | 紧急费(元) | 紧急量(kWh) | 当日负载 MAE(kW) |
|---|---|---|---|---|
| 2025-06-01 | 端午 | 139,459 | 33,998 | 1,295 |
| 2025-06-02 | 端午调休 | 79,851 | 19,055 | 721 |
| 2025-04-06 | 清明 | 79,390 | 18,257 | 1,064 |
| 2025-05-04 | 劳动节 | 72,777 | 18,073 | 1,192 |
| 2025-10-05 | 国庆 | 70,961 | 16,724 | 1,165 |
| 2025-05-01 | 劳动节 | 70,902 | 15,771 | 1,022 |
| 2025-05-05 | 劳动节 | 63,175 | 14,940 | 931 |
| 2025-09-28 | 国庆调休前周日 | 62,641 | 15,170 | 640 |

Top8 合计约 60 万元，占全年紧急费的近 1/3。

**数据层面的根因**（核对附件 2 原始负载）：这批数据中"节假日"负载形态并不统一——春节假期(1/31–2/1)、清明(4/4–4/5)、劳动节中段(5/2–5/3)、国庆中段(10/3–10/4) 呈 ~3000 kW 的**深度假日负载**；而元旦、春节前段(1/28–1/30)、5/1、5/4–5/5、端午(6/1–6/2)、国庆首尾(10/1–10/2, 10/5–10/8) 呈 ~5000 kW 的**正常水平负载**。节假日选样池只有少量历史样本且深度假日占多数（春节 8 天中的多日），导致节假日点预测被系统性拉低约 2000 kW → 计划偏小 → 实际高负载节假日爆发紧急购电。

**定性**：这不是求解错误或信息泄漏（当天实际数据从未进入计划），而是"节假日小样本预测器"的固有尾部风险，属于本模型（文档 §3.3 规则）在数据异质性下的正常表现。该现象为论文提供三个有价值的论证点：

1. 说明五倍惩罚下预测误差的费用放大效应（紧急电量仅 2.12%，费用占 11.78%）；
2. 正是问题三"日内预报调整计划"的量化动机（节假日中午 12:00 的预报可纠正上午的偏差）；
3. 也是文档 §6 CVaR 风险控制扩展（λ>0）能改善的典型场景。
