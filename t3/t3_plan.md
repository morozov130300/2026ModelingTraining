# 问题三建模框架（给定负荷下的储能协同优化）

## 0. 赛题原文与"切断"原则

赛题正文第 17 行明确规定：

> 问题三以 region_time_data.xlsx 中的 Baseline_AI_IT_Load_MW 与 NonAI_IT_Load_MW 作为给定 IT 负荷，其中设施负荷按"给定 IT 负荷 × 区域 PUE"计算。参赛队仅优化储能充放电、购售电及新能源分配策略，**不重新优化任务迁移与任务开工时段**。

因此问题三与问题二必须"切断"：
- 给定负荷 `IT_Load(r,t) = Baseline_AI_IT_Load_MW + NonAI_IT_Load_MW`（已核验：该口径与数据中 `IT_Load_MW` 仅差 5e-5 MW，说明基准就是按此生成的）；
- 设施负荷 `Total_Load = IT_Load × PUE(r)`；
- 决策面只剩：储能充放电（RenewableCharge / GridCharge / Discharge）、购电、售电/外送、新能源分配。

问题三研究的是：**在完全相同的计算负荷下，仅靠储能与新能源管理还能改善多少**——从而单独识别储能本身的贡献。

### 1.2 可再生与负荷的全局关系（决定储能价值的根本）

- `AvailableRenewable_MW` **六个区域完全相同**：min=500、mean≈800、max=1100；
- 给定设施负荷峰值：A 554 / B 531 / C 537 / D 648 / E 630 / F 651 MW；
- `R < TL` 的小时数：A/B/C/D/E 均为 **0**，仅 RegionF 有 **1 小时**（缺口 31.6 MW）；
- 基准 GridPurchase 峰值均低于 MaxGridImport（A 497<550、B 468<520、C 455<510、D 463<510、E 331<370、F 307<340），**合同购电上限从未被触碰**；
- D/E/F 的基准 NetGridImport 分别有 496/1407/957 小时为负（外送抵减）。

**含义**：在"可再生优先"口径下，购电≈0、碳排≈0、峰值净购电≈0——储能没有传统意义上的"削峰填谷"对象。储能的可识别增量价值集中在：
1. **弃电转外送**（D/E/F）：把无法外送的富余可再生充入储能，在外送未饱和的边缘小时放电，把弃电"顶成"外送收入；
2. **F 区唯一紧张小时的削峰**（31.6 MW）；
3. **新能源利用率指标**（官方口径含"新能源充电"项，储能充电直接提高利用率）；
4. **替代基准的 GridCharge 套利**（基准 A 区电网充电 4385 MWh，优化中应由可再生充电替代）。

### 1.3 基准画像（对比锚点）

- 总购电 4,134,366 MWh、总碳排 2,045,367 tCO2、总弃电约 776 万 MWh、利用率约 32.7%；
- 每区域均为"约 500 充电小时 / 500 放电小时"的规整策略，SOC 终值均高于初始（A 206.8>157.5 等）；
- 基准不是可再生优先（R≥TL 仍大量购电），因此相对基准的大幅改善必须做归因拆分。

### 1.4 基准口径与问题二报告的差异（已精确定位，报告必须说明）

对同一份 region_time_data 全时域（0–2406，14442 行）核算：

| 指标 | 附件官方口径 | 数值 | 问题二报告所用口径 | 数值 |
|---|---|---|---|---|
| 基准购电 | `GridPurchase`（毛购电，含 GridCharge、不扣外送） | 4,134,366.12 MWh | `Σ max(0, NetGridImport)`（**正净购电**，外送抵减且负值截断为 0） | 3,129,066.76 MWh ✓ 精确吻合 |
| 基准成本 | `Σ(GridPurchase×ρ − GridSell×φ)` | 1,801,660,138 元 | 简化口径，**无法从附件字段复现** | 1,250,567,377 元 |
| 基准碳排 | `Σ GridPurchase×ξ` | 2,045,367.48 tCO2 ✓ 一致 | 同左 | 2,045,367.48 tCO2 |

**结论**：问题二报告把"购电"用了正净购电口径，与附件字段 `GridPurchase` 不一致；碳排两报告一致。**问题三报告统一采用附件官方口径**（与 region_time_data 字段一一对应、与附件基准直接可比），并在报告开头注明与问题二的口径差异及修正后的基准数字。

## 2. 官方口径（附件 1 统一公式）

- 能源平衡（含储能）：`GridPurchase + AvailableRenewable + DischargePower = Total_Load + ChargePower + GridSell + Curtailment`
- SOC 递推：`SOC(t) = SOC(t−1) + ηc·ChargePower(t) − DischargePower(t)/ηd`（SOC 为时段末状态，InitialSOC 为第 0 小时前状态；已用基准数据验证）
- 终端约束：`SOC(2406) ≥ InitialSOC`（保证同一储能库存下比较）
- 电费：`Σ GridPurchase×ρ − Σ GridSell×φ`
- 碳排放：`Σ GridPurchase×ξ`（按购电，非净购电）
- 新能源利用率：`(直接消纳 + 新能源充电 + 新能源外送) / 可用新能源`（**含"新能源充电"项，储能直接贡献此项**）
- 购售电边界：`GridPurchase ≤ MaxGridImport`、`GridSell ≤ MaxGridExport(SellLimit)`（区域级硬约束；不建模跨区潮流）

## 3. 模型（线性规划，可精确求解）

### 3.1 决策变量（每区域每 2407 小时）
- `cR(r,t)` 新能源充电功率、`cG(r,t)` 电网充电功率（`Charge = cR + cG`）
- `d(r,t)` 放电功率
- `q(r,t)` 购电功率、`y(r,t)` 外送/售电功率
- `s(r,t)` SOC（状态变量，时段末）
- 直接消纳 `u(r,t)`、弃电 `w(r,t)` 可由平衡式消去或显式保留

### 3.2 约束（每区域，r=1..6，t=0..2406）
- 平衡式（见 §2）
- SOC 递推 + `MinSOC ≤ SOC(t) ≤ C` + `SOC(2406) ≥ InitialSOC`
- **第 2406 小时充放电为 0**（已定）：`cR(r,2406)=cG(r,2406)=d(r,2406)=0`，即 `SOC(2406)=SOC(2405)` 且须 ≥ InitialSOC——2406 仅作终端结算
- `0 ≤ cR+cG ≤ P_ch`、`0 ≤ d ≤ P_dis`（充放互斥由目标自动保证，或加 `cR+cG + d ≤ max(P_ch,P_dis)` 松弛）
- `cR ≤ R − u`（可再生充电不能超过富余）、`cG ≤ MaxGridImport − q`（电网充电包含在购电上限内）
- `q + cG' ≤ MaxGridImport`（口径：GridPurchase 含 GridCharge，见字段说明）、`y ≤ SellLimit`
- 可再生守恒：`R = u + cR + y + w`，`u ≤ TL`（可再生优先由目标自然实现）

### 3.3 目标与多目标结构
- 主方案：`min C + λE`（λ 为碳价，同问题二手法，做 λ 灵敏度）
- 削峰导向：在 `min C + λE` 下追加 `NetGridImport(r,t) ≤ P_target` 约束，扫描 `P_target` 得到**成本—峰值前沿**；
- 利用率导向：追加 `利用率 ≥ K_target` 约束，扫描得到**成本—利用率前沿**（储能充电在此起直接作用）；
- 负荷波动指标（**已定口径**）：主 KPI 为**区域级 `NetGridImport` 逐时标准差**；优化代理用**峰谷差 `max−min`**（线性，可进 LP，用于"波动导向"方案的约束/目标），报告用标准差展示平滑效果。理由：① Total_Load 固定，储能唯一能平滑的是电网侧净购电；② 标准差连续、对储能充放敏感；③ 标准差非凸，不能直接进 LP 目标。实测方案 1（无储能）下 A/B/C 净购电恒为 0（波动 0），波动指标主要作用于有外送的 D/E/F（std 30–46 vs 基准 110–135），报告需注明。

**与问题二的方法论对比（论文亮点）**：问题二 50000 任务整数决策只能启发式；问题三变量 ~7 万、约束线性，**用 LP 求解器（HiGHS/linprog/pulp）直接求全局最优**——精确解 vs 启发式的对照本身就是写作亮点。

## 4. 归因与对比结构（问题三的"功劳拆分"）

| 方案 | 内容 | 隔离出的贡献 |
|---|---|---|
| 方案 0 | 附件基准（直接读取 region_time_data） | 起点 |
| 方案 1 | 无储能 + 可再生优先（给定负荷下 q=max(0,TL−R)，即问题二能源口径套在给定负荷上） | "可再生优先消纳"口径的贡献 |
| 方案 2 | 有储能 LP 优化（主方案 min C+λE） | **储能的增量经济/碳贡献** |
| 方案 3 | 削峰导向（峰值约束扫描） | 储能的削峰价值 |
| 方案 4 | 利用率导向（利用率约束扫描） | 储能的消纳/利用率价值 |

**核心归因**：方案 1 → 方案 2 的差额 = 储能本身的贡献（预期在本题数据下较小：弃电转外送、F 区 1 小时、利用率提升）；方案 0 → 方案 2 的巨额差异主要来自口径，不能整体归因于储能。

**敏感性场景（衔接问题四）**：
- 可再生消纳上限 α（物理限制下储能价值会上升）；
- 储能容量 ×k（k=0.5/1/2，价值—容量曲线）；
- 碳价 λ（购电不为 0 时储能放电才有碳价值）；
- 若场景中引入 R 下降 20%（极端波动），储能削峰价值立即放大——为问题四"新能源极端波动场景"做铺垫。

## 6. 论文结构与创新点

结构：问题重述与"切断"依据 → 储能数据画像与可再生-负荷全局关系 → 官方口径（含 SOC 验证）→ LP 模型 → 四方案归因 → 前沿分析 → 敏感性 → 与问题四衔接。

创新点建议（不写"采用了某某算法"）：
- **精确求解**：问题三是全题唯一能直接求全局最优的子问题，与问题二的启发式形成方法论对照；
- **增量归因**：用"无储能 vs 有储能"隔离口径与储能的贡献，避免把可再生优先的收益误记到储能头上；
- **机制解释**：把储能价值归结为"弃电→外送收入搬运 + 边缘小时削峰 + 利用率口径贡献"三个可量化的渠道，而不是笼统的削峰填谷；
- **场景敏感性**：展示储能价值随可再生充裕度变化的规律，为问题四极端场景提供前置结论。

## 7. 决策记录与剩余待定点

**已拍板**：
1. **第 2406 小时充放电 = 0**（已定）：2406 仅作终端结算，`SOC(2406)=SOC(2405) ≥ InitialSOC`（已固化进 §3.2）；
2. **负荷波动指标**（已定）：优化代理用区域级 NetGridImport 峰谷差（线性），主 KPI 报告用标准差（已固化进 §3.3）；
3. **基准购电口径**（已查清）：问题二报告的 3,129,067 MWh = `Σ max(0, NetGridImport)`（正净购电）；问题三统一用附件官方口径 `GridPurchase`（4,134,366 MWh）并注明差异（已固化进 §1.4）。

**剩余待定点**：
1. **λ 取值与 α 上限范围**：参照问题二校准（50–500 元/tCO2；α 建议 50%–100%）；
2. **方案 1（无储能）中"给定负荷"的 AI 负荷用 Baseline_AI_IT_Load_MW**——与问题二方案 A 的区别是任务不可调，报告需写清。

## 8. 与问题四的接口

问题四 = 问题二（任务调度）+ 问题三（储能）联合优化。本框架的敏感性结果（储能价值随 R 下降/α 收紧而上升）直接支撑问题四"新能源极端波动场景"下算-储-电协同的必要性论证；λ 灵敏度与问题二呼应。
