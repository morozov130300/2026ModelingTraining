# 问题四“算—储—电”联合优化结果分析报告

## 1. 研究目标与实现框架

问题四将任务迁移、任务时间平移、区域 GPU/IT 容量、网络时延、动态新能源、购售电和储能统一纳入多区域联合优化。程序严格按照 [t4_plan.md](t4_plan.md) 采用两层反馈结构：

- **外层任务调度**：决定任务执行区域和整数开工小时，实时任务必须在源区域到达即执行，弹性任务可在满足时延和截止时间的前提下迁移或延迟。
- **内层能源 LP**：对 6 个区域分别求解 2407 小时储能与能源调度，处理能源平衡、新能源守恒、SOC、充放电功率、购售电上限和终端 SOC 等约束。
- **双向反馈**：内层根据负荷方案返回能源成本和负荷平衡约束影子价格，外层使用边际供电成本信号重新安排任务，直到目标值收敛或达到最大反馈轮数。

本次运行采用以下参数：

| 参数 | 取值 |
|---|---:|
| 任务数 | 50,000 |
| 调度时域 | 0–2406 小时 |
| 最后执行小时 | 2405 |
| 外层候选窗口 | 48 小时 |
| 外层批规模 | 2,000 个任务 |
| 碳价 λ | 200 CNY/tCO₂ |
| 可再生能源利用上限 α | 1.0 |
| 最大反馈轮数 | 3 |
| 实际反馈轮数 | 2 |
| 运行 worker | 8 |
| 敏感性场景数 | 16 |

程序完整运行完成，生成了 A0–A4 消融结果、A4 调度结果、A3/A4 能源时序、反馈收敛结果、约束验证结果和 16 个敏感性场景结果。

### 3.2 A0：本地执行基准

A0 将所有任务限制在源区域执行，并采用无储能的能源后处理。结果显示：

- 50,000 个任务全部完成，迁移数为 0，加权平均时延为 5 ms。
- 全系统仅购电 31.60 MWh，碳排 8.85 tCO₂，说明原始任务负荷与新能源曲线整体匹配较好。
- 外送新能源 1,330,191.13 MWh，新能源利用率为 67.91%。
- 峰值净购电为 31.60 MW，购电压力集中在少数新能源不足时段。

A0 说明本数据集在常规新能源供给下已经具有较高的可再生能源覆盖能力，但无储能时仍存在少量购电和碳排。

### 3.3 A1：跨区域迁移的影响

A1 允许弹性任务跨区域迁移，但不引入储能优化。共有 26,616 个任务迁移，占全部任务的约 53.23%。迁移后：

- 加权平均时延由 5.00 ms 上升到 27.81 ms，最大时延达到 82 ms，但旧结果的 A1 调度明细未单独落盘，当前不能从 A4 调度文件反推出这 82 ms 对应的任务类型。因此报告不再擅自声称“82 ms 均发生在 AITraining”；修复后重跑时应保存 A1 调度表，并按 `TaskType` 核查最大时延任务。按题目时延约束，若 82 ms 出现在 BatchInference（上限 80 ms）将不合规，若出现在 AITraining（上限 150 ms）则合规。
- 购电量由 31.60 MWh 增加到 6,106.75 MWh，碳排由 8.85 tCO₂ 增加到 1,520.65 tCO₂。
- 新能源利用率从 67.91% 降至 66.75%。
- 按当前统一能源口径，A1 的目标值高于 A0，未体现出经济收益。

这一结果表明，在当前数据和当前构造式外层调度下，单纯扩大空间迁移并不必然降低系统目标。迁移会改变各区域逐时负荷分布，可能把任务从新能源覆盖较好的源区域转移到某些时段能源缺口更明显的区域；同时，迁移还会增加网络时延。因而“低电价区域迁移”不能脱离逐时能源、储能和容量约束单独判断。

A1 与问题二方案 B 不能直接按迁移数或成本比较：问题二方案 B 使用了问题二的可再生优先、外送机会成本评分和时刻搜索，结果为迁移 28,660 个、购电 0、外送 1,464,718.64 MWh；旧 Q4 A1 使用了另一套到达优先调度与信号，结果为迁移 26,616 个、购电 6,106.75 MWh。两者决策空间和评分机制不一致，旧 A1 不能作为“迁移模块边际收益”的干净估计。代码已将 A1 与 A2 统一到同一问题二口径信号，后续应以重跑后的同口径结果进行消融。

### 3.4 A2：时间平移的结果与实现修正

本次已生成的旧结果中，A2 与 A0 完全一致；但该现象**不能解释为时间平移无价值**。旧实现的 `initial_signal()` 在新能源覆盖非 AI 负荷时直接把信号置为 0，导致第 1 轮外层调度的所有候选时刻缺少能源区分度，贪心调度保持原始方案。因此，旧结果中的 A2=A0 是**信号未接通造成的实现退化**，不能用于归因时间平移的经济价值。

已修正代码：A1 与 A2 现在统一使用问题二口径的逐时边际能源信号：

- 新能源不足时使用购电价格 `ρ+λξ`；
- 新能源富余但不超过外送上限时计入减少外送的机会成本 `φ`；
- 新能源富余且超过外送上限时，新增任务只减少弃电，边际成本为 0；
- A1 与 A2 的区别仅保留为是否允许弹性任务在到达—截止窗口内进行时间平移，避免消融同时更换信号源。

因此，旧 A2 数值只能作为“修复前实现基线”保留，不能作为正式时间平移归因。问题二方案 A 已提供独立实证：不迁移但进行调时后，购电由 31.60 MWh 降至 0，外送达到 1,464,044.68 MWh，目标改善约 33.12 million CNY。修复后的 A2 必须重新完整运行后，才能用问题四自身的 A2 结果进行正式归因。

### 3.5 A3：储能优化的贡献

A3 可以近似对应问题三的“方案 2：固定任务方案 + 储能优化”。本次旧结果中的 A3 运行成本为 -459,195,912.69 CNY、外送量为 1,491,607.14 MWh；问题三方案 2 的对应结果为 -459,206,011.64 CNY、1,491,657.12 MWh。两者差异约 10,098.95 CNY 和 49.98 MWh，来源是问题四按实际调度任务重新聚合得到的负荷，与问题三附件基线负荷之间存在微小差异。两者应视为同一能源侧机制下的近似对应，而不是要求数值完全相同。

A3 在固定 A2 任务方案的基础上引入区域储能 LP，结果改善明显：

- 运行成本从 -419,793,343.27 CNY 降至 -459,195,912.69 CNY，改善约 39,402,569.43 CNY。
- 购电量从 31.60 MWh 降至 0 MWh。
- 碳排从 8.85 tCO₂ 降至 0。
- 新能源外送量增加到 1,491,607.14 MWh。
- 新能源利用率由 67.91% 提升到 69.51%。
- 峰值净购电降至 0 MW。

因此，在本数据集上，储能是最明确、最稳定的成本和碳排改善来源。其核心作用不是改变任务执行方案，而是在新能源富余时充电、在新能源不足时放电，将时序上的新能源供需错配转化为可消除的储能调度问题。

### 3.6 A4：完整联合反馈的边际贡献

A4 的 27 个迁移任务使外送量增加 565.25 MWh，但新能源外送上限的理论总容量为：

\[
620\ \text{MW}\times 2407\ \text{h}=1,492,340\ \text{MWh}。
\]

A4 外送量为 1,492,172.39 MWh，已达到理论上限的 **99.9888%**。因此，外送通道几乎饱和，任务迁移能够创造的新增外送空间极小；565.25 MWh 的增量以约 193 CNY/MWh 的量级折算，约对应 109,028 CNY 的 A4 边际改善。这解释了为什么 A4 的联合反馈收益存在但很小。

A4 的新能源利用率应使用未四舍五入值比较：A3 为 **0.6951429206**，A4 为 **0.6951099961**。A4 虽然外送量更高，但迁移改变了区域和时段负荷分布，使部分时段直接消纳量下降；由于利用率分母是全量可用新能源，直接消纳下降幅度略大于外送增加幅度，故利用率反而低 **0.0000329245**。这不是代码错误，而是指标分子各组成项变化后的正常结果。

## 4. A4 反馈收敛分析

A4 在第 2 轮达到收敛：

| 反馈轮次 | 目标值/CNY | 计划任务数 | 信号均值 | 相对变化 |
|---|---:|---:|---:|---:|
| 1 | -459,195,912.69 | 50,000 | 0.0000 | — |
| 2 | -459,304,940.51 | 50,000 | 1.8445 | 0.000237376 |

收敛表中的“信号均值”定义为当前反馈轮次传入外层调度器的区域—小时信号数组均值：

\[
\text{SignalMean}=\frac{1}{|R|H}\sum_{r,t}M_{r,t}^{(k-1)}。
\]

它不是目标值、归一化指标或影子价格的绝对值最大值。旧结果第 1 轮 SignalMean=0.0000，正是 H1 所指出的初始信号未接通证据；第 2 轮 SignalMean=1.8445 则来自第 1 轮能源 LP 返回的影子价格。修复后重新运行时，应重新记录该字段，不能继续把旧表解释为时间平移已经被有效评估。


\[
\frac{|Obj^{(k)}-Obj^{(k-1)}|}{|Obj^{(k)}|}<10^{-3}.
\]

第 2 轮相对变化为 0.000237376，小于 0.001，因此停止反馈。该结果表明：

1. 第 1 轮能源 LP 基于初始能源信号得到完整可行调度；
2. 内层返回影子价格后，第 2 轮仅对少量任务进行重新安排；
3. 重新求解能源 LP 后目标值继续改善；
4. 改善幅度已低于预设收敛阈值，无需继续执行第 3 轮。

这与计划文档中“通常 2–4 轮稳定”的预期一致。

λ 取 0、50、100、200、300、500 CNY/tCO₂ 时，所有主要结果完全一致：

- 任务数均为 50,000；迁移数均为 27；
- 目标值均为 -459,304,940.51 CNY；
- 购电量均为 0 MWh；

原因是常规场景下储能优化已经把购电和碳排降至 0，λ 无法进一步改变碳排结果。因此 λ 扫描在当前宽松场景下退化为同一点，不能单独展示成本—碳排权衡；必须结合 α 收紧或新能源下移压力场景分析碳价效果。

### 5.4 新能源下移 20% 场景

该场景的实现口径是对六个区域每小时可用新能源统一乘以 0.8，即 `R_r(t) ← 0.8R_r(t)`，同时保持 `α=1.0`。在问题三的固定负荷能源模型中，这与直接设置 `α=0.8` 具有相同的新能源可行域，因此问题三报告中两者结果一致。

问题四中两者结果不完全一致：α=0.8 场景购电 112.33 MWh、碳排 69.91 tCO₂、迁移数 0；新能源下移 20% 场景购电 385.10 MWh、碳排 182.46 tCO₂、迁移数 24。原因不是能源 LP 可行域本身不同，而是问题四在能源 LP 外层增加了构造式任务调度：两种等价能源口径经过不同的初始信号、任务排序和局部贪心路径后，可能得到不同的局部任务方案，随后内层 LP 评估的是不同负荷分布。问题三没有外层任务调度，因此能直接体现等价性；问题四的等价性只能在固定任务方案或全局外层最优条件下保持，不能要求启发式局部解完全一致。

在本次旧结果的 `R×0.8, α=1.0` 场景下：

- 任务数仍为 50,000；迁移数为 24；
- 加权平均时延为 5.034 ms，最大时延为 65 ms；
- 运行成本为 -395,925,633.80 CNY；
- 购电量为 385.10 MWh；
- 碳排为 182.46 tCO₂；
- 目标值为 -395,889,142.10 CNY；
- 新能源利用率提高到 83.68%。

新能源总量下移后，系统仍可通过储能和少量购电保持任务全量完成，但零购电、零碳排状态被打破。新能源利用率上升并不表示系统绝对表现变好，而是因为可利用新能源总量下降后，实际消纳量占剩余可用新能源的比例提高；评价时应同时关注购电量、碳排和弃电量。

## 6. 主要结论

### 6.1 储能是当前数据集的主导收益来源，但旧 A2 基准需重算

在旧结果中，A2 到 A3 的能源侧改造带来约 39.40 million CNY 的目标改善，并消除了全部购电和碳排；不过旧 A2 存在 H1 所述的信号未接通问题，因此这个差值不能继续作为最终“储能相对有效时间平移方案”的严格归因。A3 与问题三方案 2 的近似对应仍然成立，但修复后的 A2/A3/A4 必须重新运行后，才能发布新的 A2→A3 和 A3→A4 归因。

当前可以保留的稳健结论是：在本数据集上，储能 LP 能显著利用新能源时序错配、降低购电和碳排；但其相对于任务调度模块的精确边际贡献必须基于修复后的同口径 A2 重新计算。

### 6.2 当前结果中存在两种不同的“信号退化”

必须区分：

1. **实现层信号缺失（已修复）**：旧 A2/A4 第 1 轮传入的 `initial_signal` 在大部分时段被错误置为 0，导致 SignalMean=0.0000，外层时间平移没有真正被激活。
2. **模型层信号退化（仍可能存在）**：即使使用正确的初始信号，在 α=1.0 且储能足够的场景下，LP 返回的负荷平衡影子价格仍可能大量接近 0，因为购电和碳排已经被储能消除。

只有第二种现象才能用于解释修复后常规场景下任务侧动作较少；不能用它为旧 A2=A0 的结果辩护。

### 6.3 约束编号映射

问题四当前报告中的 C1–C11 与问题二并非同一套编号，不能直接横向引用。对应关系如下：

| 问题四编号 | 问题四含义 | 问题二对应口径 |
|---|---|---|
| C1 | 任务唯一分配 | C1 |
| C2 | 实时任务到达即开工、本地执行 | C2 |
| C3 | 网络时延 SLA | C3 |
| C4 | 任务截止时间 | C4 |
| C5 | 不占用 2406 小时 | C7 |
| C6 | GPU 容量 | C5 |
| C7 | IT 功率容量 | C6 |
| C8 | 毛购电上限 | 问题二 C8 的购售电边界扩展 |
| C9 | SOC 上下限 | 问题二无储能对应项 |
| C10 | 终端 SOC 不低于初始值 | 问题二无储能对应项 |
| C11 | 2406 小时不充放电 | 问题二无储能对应项 |

后续论文共用时应采用“问题编号 + 含义”双重标注，避免把问题四 C5 误读为问题二的 GPU 容量约束。

### 6.4 压力场景主要激活储能侧，任务侧激活取决于信号区分度

表 5.2 显示，α=0.5–0.8 的高压力场景迁移数均为 0，而 α=0.9 和 α=1.0 分别为 66 和 27。因此不能笼统地写成“压力场景才真正激活任务—能源联合优化”。本次结果更准确的解释是：α 收紧首先激活储能侧和购电侧，购电价格在六个区域具有同向主导作用，外层构造式信号在区域之间的相对区分度反而不足，所以任务迁移未被触发；α=0.9–1.0 时储能外送机会成本和局部剩余结构保留了更多时空差异，才出现少量迁移。

因此，当前数据下的结论应改为：**压力场景稳定激活能源侧耦合，但任务侧是否发生迁移取决于影子价格的区域—时间区分度以及启发式路径，不能仅由压力强弱判断。**

### 6.5 迁移不能只看平均电价

A1 虽然迁移了 26,616 个任务，但在统一能源 LP 口径下成本和碳排均高于 A0。这说明迁移决策必须同时考虑：

- 逐时新能源供给；
- 储能充放电状态；
- 区域购电上限；
- IT 功率与 GPU 容量；
- 网络时延代价；
- 任务的到达与截止窗口。

单独依据区域平均电价或平均碳强度进行迁移，可能把负荷推向不利时段，反而增加系统能源成本。

### 6.6 储能扩容存在明显边际递减

容量减半会造成明显的目标恶化，但容量加倍只带来约 14.46 thousand CNY 的进一步改善，表明基准容量已经接近当前负荷与新能源曲线下的有效配置区间。后续若要继续提高储能投资价值，应优先研究更严格的 α、更低的新能源出力或更高的任务负荷，而不是在当前宽松场景下单纯扩容。

## 7. 结果使用边界与后续分析建议

1. 旧 A0/A1/A2/A3/A4 表格只可作为修复前运行记录；由于 A2 初始信号缺失，修复后必须重新生成 A0–A4、敏感性分析和全部图表，新的结果才可用于最终归因。
2. 成本为净运行成本，负值主要来自新能源外送收入，不能直接解释为传统意义上的电费支出。
3. λ 扫描在 α=1.0 常规场景下可能退化，论文或正式报告中应重点展示 α≤0.8 和新能源下移 20% 的结果，并区分初始信号缺失与 LP 影子价格退化。
4. A1 与问题二方案 B 的结果不能直接比较，除非统一评分函数、任务排序、候选窗口和外层调度机制。
5. 本次代码修复不改变任务数量、容量约束、SLA、LP 约束或反馈轮数；只修正初始边际能源信号并统一 A1/A2 的初始信号来源。
