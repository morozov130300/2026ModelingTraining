# 问题四“算—储—电”联合优化结果分析报告

## 1. 研究目标与实现框架

问题四将任务迁移、任务时间平移、区域 GPU/IT 容量、网络时延、动态新能源、购售电和储能统一纳入多区域联合优化。程序按 [t4_plan.md](t4_plan.md) 的两层反馈结构实现：

- **外层任务调度**：决定任务执行区域和整数开工小时；实时任务在源区域到达即执行，弹性任务可在时延 SLA、截止时间与容量约束内迁移或延迟。
- **内层能源 LP**：对六个区域分别求解 2,407 小时储能与能源调度，处理能源平衡、新能源守恒、SOC、充放电功率、购售电上限和终端 SOC 约束。
- **双向反馈**：内层返回能源成本及负荷平衡影子价格，外层基于逐时边际供电成本重新调度，直到达到收敛阈值或最大反馈轮数。

本次为修正初始信号后的完整重运行，参数如下。

| 参数 | 取值 |
|---|---:|
| 任务数 | 50,000 |
| 调度时域 | 0–2406 小时 |
| 最后执行小时 | 2405 |
| 外层候选窗口 | 48 小时 |
| 外层批规模 | 2,000 个任务 |
| 碳价 λ | 200 CNY/tCO₂ |
| 可再生能源利用上限 α | 1.0 |
| 最大反馈轮数 | 3 |
| 实际反馈轮数 | 2 |
| 运行 worker | 8 |
| 敏感性场景数 | 16 |

## 2. 总体可行性与约束验证

本次运行共调度 50,000 个任务，`summary.json` 中 `scheduled_task_count=50000` 且 `all_constraints_passed=true`。最终 A4 解的约束复核结果均为 PASS：

| 检查项 | 结果 | 含义 |
|---|---|---|
| C1 任务分配 | PASS | 每个任务恰执行一次 |
| C2 实时任务 | PASS | 实时任务到达即开工 |
| C3 网络时延 SLA | PASS | 所有迁移满足时延约束 |
| C4 截止时间 | PASS | 所有任务在截止时间前完成 |
| C5 调度边界 | PASS | 没有任务占用 2406 结算小时 |
| C6 GPU 容量 | PASS | 外层逐时 GPU 容量约束满足 |
| C7 IT 功率 | PASS | 各区域 IT 功率不超过上限 |
| C8 购电上限 | PASS | 各区域毛购电不超过上限 |
| C9 SOC 上下限 | PASS | 储能 SOC 始终处于允许范围 |
| C10 终端 SOC | PASS | 2406 小时 SOC 不低于初始 SOC |
| C11 2406 小时充放电 | PASS | 结算小时不充电、不放电 |

因此，下文结论均基于任务全量完成、未放宽约束的可行解。成本采用题目规定的“购电成本减售电收入”口径，故运行成本可能为负；目标值为运行成本与 λ×碳排之和。

### 3.2 A0：本地执行基准

A0 的 50,000 个任务均在源区域到达即执行，迁移数为 0、加权平均时延为 5 ms。无储能条件下仍仅需购电 31.60 MWh、产生碳排 8.85 tCO₂，说明原始负荷与新能源曲线总体匹配较好；但其外送量为 1,330,191.13 MWh，仍存在显著的时序消纳空间。

### 3.3 A1：空间迁移的影响

A1 与 A2 使用相同的初始边际能源信号，A1 仅限制弹性任务不主动改变开工时刻，因此可作为“仅放开空间迁移”的消融基线。A1 共迁移 4,041 个任务，但没有时间平移。

- 相比 A0，运行成本改善 2,856,427.10 CNY；考虑碳排后，目标值改善 2,244,957.06 CNY。
- 迁移使外送量增加 26,785.39 MWh，但购电升至 6,247.01 MWh，碳排升至 3,066.20 tCO₂，说明只改变任务所在区域会将一部分负荷推入新能源不足时段。
- 最大时延为 82 ms。对 `schedule_A1.csv` 的核查显示，全部 50 个 82 ms 任务均为 **AITraining**，其 SLA 上限为 150 ms；因此均满足 C3。该链路未用于 BatchInference（上限 80 ms）或 RealTimeInference。

问题二方案 B 与 A1 不能直接以迁移数或成本横比。问题二方案 B 允许时刻搜索并使用其完整的动态候选评分；A1 则是“相同初始信号、仅空间迁移”的受限消融，两者决策空间不同。

### 3.4 A2：初始信号修复后，时间平移已被激活

旧版结果中的 `A2=A0` 是实现层信号缺失导致的退化，不能用于说明时间平移无价值。本次重运行中，初始能源信号改为问题二口径：新能源不足时取 `ρ+λξ`，新能源富余但未达到外送上限时取售电机会成本 `φ`，外送饱和后的弃电区间边际成本为 0。

修复已实际激活任务侧决策：A2 共发生 **4,439 次时间平移**，其中 4,432 次为同区域调时、7 次同时发生迁移与调时；总迁移数为 22。相对 A0：

- 运行成本改善 **11,244,995.82 CNY**；
- 含碳价目标值改善 **11,235,807.18 CNY**；
- 外送量增加 35,726.92 MWh；
- 购电为 105.20 MWh，仍高于 A0 的 31.60 MWh，但远低于 A1 的 6,247.01 MWh；
- 最大时延为 76 ms，低于所有相关任务 SLA 上限。

因此，当前 A2 已不再是初始方案的机械复制。它显示时间平移能够显著改善净运行收益，但在无储能的局部启发式调度下，不能保证同时使购电量最小。问题二方案 A 的约 33.12 million CNY 改善仍是其不同调度机制下的独立对照，不能与本问题的 A2 直接合并为同一指标。

### 3.5 A3：储能优化的贡献

A3 固定 A2 任务方案后求解区域储能 LP。相对 A2：

- 运行成本及目标值再改善 **28,279,357.52 CNY**；
- 购电由 105.20 MWh 降至 0，碳排由 54.79 tCO₂ 降至 0；
- 外送增加至 1,492,164.22 MWh；
- 新能源利用率由 68.22% 提升至 69.48%。

A3 近似对应问题三的“固定任务方案 + 储能优化”。与问题三方案 2 的数值存在小幅差异，原因是问题四使用修复后 A2 的实际调度负荷，而问题三使用其固定基线负荷；两者不应要求数值完全相同。

### 3.6 A4：采用历史最优反馈轮作为最终联合方案

A4 第 1 轮采用修复后的初始信号，得到目标值 -459,306,737.86 CNY，与 A3 相同；第 2 轮接收 LP 影子价格后得到 -459,236,582.36 CNY。第 2 轮相对变化为 0.000152759，小于 0.001 的停止阈值，但目标值较第 1 轮劣化 70,155.50 CNY，外送量减少 351.55 MWh。

因此，程序已改为在每个反馈场景中保留全部已求得可行轮次的 **incumbent（历史最优）**，并将目标值最小的轮次作为 A4 最终输出，而不是机械保留最后一轮。对本次基准场景，历史最优为第 1 轮，故 A4 与 A3 数值相同：这表示完整反馈在宽松场景下没有带来额外收益，而不是联合优化优于储能优化。

外送理论总上限为：

\[
620\ \text{MW}\times 2407\ \text{h}=1,492,340\ \text{MWh}。
\]

A3/A4 外送量为 1,492,164.22 MWh，达到理论上限的 **99.9882%**。外送通道已近乎饱和，可供影子价格驱动进一步改进的空间极小；第 2 轮回摆说明“相邻轮次变化小”仅代表数值稳定，不等价于最后一轮更优。

## 4. A4 反馈收敛分析

下表记录本次反馈的逐轮轨迹；`convergence.csv` 已同时记录每轮截至当前的 `BestObjective_CNY` 和 `BestIteration`，最终输出采用其中的历史最优轮。

| 反馈轮次 | 当轮目标值/CNY | 当时历史最优/CNY | 计划任务数 | 信号均值 | 相对变化 |
|---|---:|---:|---:|---:|---:|
| 1 | -459,306,737.86 | -459,306,737.86 | 50,000 | 11.8960 | — |
| 2 | -459,236,582.36 | -459,306,737.86 | 50,000 | 0.5455 | 0.000152759 |

“信号均值”定义为传入外层调度器的区域—小时能源信号平均值：

\[
\text{SignalMean}=\frac{1}{|R|H}\sum_{r,t}M_{r,t}^{(k-1)}。
\]

本次第一轮 `SignalMean=11.8960`，证明初始边际能源信号已不再是旧版的全零信号；第二轮均值 0.5455 来自第一轮能源 LP 的影子价格。虽然相对变化满足停止条件，但目标值发生小幅反向变化，表明“相邻轮次变化小”只说明数值稳定，**不等价于最后一轮一定更优**。

## 5. 敏感性分析

本次完成 16 个场景：6 个碳价 λ 场景、6 个可再生能源利用上限 α 场景、3 个储能容量倍率场景，以及 1 个新能源下移 20% 场景。

### 5.1 碳价 λ 敏感性

incumbent 重运行后，λ 取 0、50、100、200、300、500 CNY/tCO₂ 的输出完全一致：目标值均为 -459,306,737.86 CNY、购电与碳排均为 0、迁移数均为 22、新能源利用率为 69.48%。

原因是该基准场景下储能已经消除了购电和碳排，碳价无法进一步改变能源 LP 的最优解。λ 的权衡作用应在 α 收紧或新能源下移等出现购电的压力场景下观察。

|---:|---:|---:|---:|---:|---:|---:|---:|
| 0.5 | 0 | 274,665,413.00 | 463,901.57 | 367,445,726.94 | 1,053,877.52 | 462.03 | 49.88% |

α 下降会显著增加购电、碳排和峰值购电压力：α=0.5 时购电达到 1,053,877.52 MWh、目标值转为正值。任务侧迁移并不随压力单调变化：α=0.5–0.7 为 0，α=0.8 为 83，α=0.9 为 46，α=1.0 为 22。

incumbent 重运行前，α=0.9 的最后一轮曾出现购电 180.30 MWh、碳排 51.54 tCO₂；历史最优选择后，分别降为 21.50 MWh 和 12.74 tCO₂，证明回摆并非应被当作最终方案。该值仍与问题三固定本地负荷在 α=0.9 下的零购电不同，且 α=0.9 的购电低于 α=0.8 的 143.85 MWh，说明 incumbent 已消除了旧结果中“α 更松反而购电更高”的末轮回摆。

因此，更准确的结论是：压力稳定激活能源与储能侧；任务迁移是否触发及其净效益取决于区域—时间边际信号的相对差异和外层求解精度，不能只由压力强弱判断。所有敏感性场景现已统一采用历史最优轮输出。

### 5.4 新能源下移 20% 场景

该场景将每个区域、每个小时的可用新能源按 `R_r(t) ← 0.8R_r(t)` 缩放，并保持 `α=1.0`。在固定任务负荷的能源 LP 中，这与设定 `α=0.8` 的新能源可行域相同。

本次 incumbent 重运行中，两者结果完全一致：迁移数均为 83、购电均为 143.85 MWh、碳排均为 83.43 tCO₂、目标值均为 -421,737,558.66 CNY。这与问题三的等价性结论一致，说明当前场景实现和历史最优选择没有引入额外的外层路径差异。

新能源总量下降后利用率升至 84.99%，不表示系统经济表现更好：可用新能源分母缩小，而购电和碳排已经增加。该场景应与购电量、碳排、弃电量和目标值共同评价。

## 6. 主要结论

### 6.1 初始信号修复已使时间平移真正参与决策

旧版 A2 的全零初始信号问题已经消除。第一轮 `SignalMean=11.8960`，A2 发生 4,439 次实际调时并相对 A0 改善 11.24 million CNY，证明时间平移已接通并产生经济影响。它不能与问题二方案 A 的数值直接等同，因为两者的候选评分与调度机制不同。

### 6.2 储能仍是当前数据集的主导收益来源

在修复后的同口径消融中，A2→A3 的目标改善为 28.28 million CNY，并将购电和碳排降至 0。储能通过在新能源富余时充电、短缺时放电，处理任务负荷与新能源出力的时序错配，是当前数据集最稳定的收益来源。

### 6.3 外层反馈的净效益取决于求解精度

A4 主场景和 α=0.9 场景共同表明，影子价格反馈并不天然保证单调改进：影子价格只对当前负荷布局局部有效，外层贪心重排可能把任务推向新能源不足时段。α=0.9 的最后一轮曾出现购电 180.30 MWh，而固定本地负荷的对照结果为零购电；这与 A4 第 2 轮相对第 1 轮劣化 70,155.50 CNY 属于同一机制。

因此，启发式反馈必须使用 incumbent：每个场景都保留目标值最小的历史可行轮，并以该轮作为最终输出，而不是只对 A4 主场景做特殊处理。代码已将该逻辑接入 `feedback_schedule()`，敏感性场景也复用同一逻辑；本次 A4 及全部敏感性结果均已按 incumbent 输出。

α=0.8/0.9 的“本地、不迁移”精确对照目前没有单独写入问题四输出；问题三固定负荷结果可作为能源侧参考，但不能冒充问题四外层对照。若论文需要严格分离“迁移净效益”，还应额外生成禁迁移的 Q4 场景，再与 incumbent 反馈结果比较。

### 6.4 反馈停止条件不等于最后一轮最优

A4 第 2 轮满足相对变化停止阈值，但比第 1 轮/A3 差 70,155.50 CNY。停止条件只判断相邻轮次的数值变化，不判断目标方向；incumbent 则保证最终报告的方案不劣于该场景已经求得的历史可行方案。
