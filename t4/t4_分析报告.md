# 问题四“算—储—电”联合优化结果分析报告

## 1. 研究目标与实现框架

问题四将任务迁移、任务时间平移、区域 GPU/IT 容量、网络时延、动态新能源、购售电和储能统一纳入多区域联合优化。程序严格按照 [t4_plan.md](t4_plan.md) 采用两层反馈结构：

- **外层任务调度**：决定任务执行区域和整数开工小时，实时任务必须在源区域到达即执行，弹性任务可在满足时延和截止时间的前提下迁移或延迟。
- **内层能源 LP**：对 6 个区域分别求解 2407 小时储能与能源调度，处理能源平衡、新能源守恒、SOC、充放电功率、购售电上限和终端 SOC 等约束。
- **双向反馈**：内层根据负荷方案返回能源成本和负荷平衡约束影子价格，外层使用边际供电成本信号重新安排任务，直到目标值收敛或达到最大反馈轮数。

本次运行采用以下参数：

| 参数 | 取值 |
|---|---:|
| 任务数 | 50,000 |
| 调度时域 | 0–2406 小时 |
| 最后执行小时 | 2405 |
| 外层候选窗口 | 48 小时 |
| 外层批规模 | 2,000 个任务 |
| 碳价 λ | 200 CNY/tCO₂ |
| 可再生能源利用上限 α | 1.0 |
| 最大反馈轮数 | 3 |
| 实际反馈轮数 | 2 |
| 运行 worker | 8 |
| 敏感性场景数 | 16 |

程序完整运行完成，生成了 A0–A4 消融结果、A4 调度结果、A3/A4 能源时序、反馈收敛结果、约束验证结果和 16 个敏感性场景结果。

## 2. 总体可行性与约束验证

本次运行共调度 50,000 个任务，调度结果中的任务数与输入任务数一致。`summary.json` 给出的 `all_constraints_passed` 为 `true`，A4 结果的全部约束检查均通过。

| 检查项 | 结果 | 含义 |
|---|---|---|
| C1 任务分配 | PASS | 每个任务恰执行一次 |
| C2 实时任务 | PASS | 实时任务到达即开工 |
| C3 网络时延 SLA | PASS | 所有迁移满足时延约束 |
| C4 截止时间 | PASS | 所有任务在截止时间前完成 |
| C5 调度边界 | PASS | 没有任务占用 2406 结算小时 |
| C6 GPU 容量 | PASS | 外层逐时 GPU 容量约束满足 |
| C7 IT 功率 | PASS | 各区域 IT 功率不超过上限 |
| C8 购电上限 | PASS | 各区域毛购电不超过上限 |
| C9 SOC 上下限 | PASS | 储能 SOC 始终处于允许范围 |
| C10 终端 SOC | PASS | 2406 小时 SOC 不低于初始 SOC |
| C11 2406 小时充放电 | PASS | 结算小时不充电、不放电 |

因此，以下经济性和调度性分析均建立在完整可行解之上，而不是基于丢弃任务或放宽约束后的近似结果。

| A3 | 固定 A2 任务方案 + 储能 LP | 0 | 5.000 | 5.0 | -459,195,912.69 | 0.00 | -459,195,912.69 | 0.00 | 1,491,607.14 | 69.51% |

注：成本为题目规定的“购电成本减售电收入”口径，因此新能源外送收入可能使运行成本为负。目标值为运行成本与 λ×碳排之和；A3/A4 因碳排为 0，目标值与运行成本相同。

### 3.2 A0：本地执行基准

A0 将所有任务限制在源区域执行，并采用无储能的能源后处理。结果显示：

- 50,000 个任务全部完成，迁移数为 0，加权平均时延为 5 ms。
- 全系统仅购电 31.60 MWh，碳排 8.85 tCO₂，说明原始任务负荷与新能源曲线整体匹配较好。
- 外送新能源 1,330,191.13 MWh，新能源利用率为 67.91%。
- 峰值净购电为 31.60 MW，购电压力集中在少数新能源不足时段。

A0 说明本数据集在常规新能源供给下已经具有较高的可再生能源覆盖能力，但无储能时仍存在少量购电和碳排。

### 3.3 A1：跨区域迁移的影响

A1 允许弹性任务跨区域迁移，但不引入储能优化。共有 26,616 个任务迁移，占全部任务的约 53.23%。迁移后：

- 加权平均时延由 5.00 ms 上升到 27.81 ms，最大时延达到 82 ms，但仍满足所有任务 SLA。
- 购电量由 31.60 MWh 增加到 6,106.75 MWh，碳排由 8.85 tCO₂ 增加到 1,520.65 tCO₂。
- 新能源利用率从 67.91% 降至 66.75%。
- 按当前统一能源口径，A1 的目标值高于 A0，未体现出经济收益。

这一结果表明，在当前数据和当前构造式外层调度下，单纯扩大空间迁移并不必然降低系统目标。迁移会改变各区域逐时负荷分布，可能把任务从新能源覆盖较好的源区域转移到某些时段能源缺口更明显的区域；同时，迁移还会增加网络时延。因而“低电价区域迁移”不能脱离逐时新能源、储能和容量约束单独判断。

A1 的结果也说明，问题四中迁移收益不能简单等同于区域平均电价差收益，必须使用完整的逐时能源 LP 进行统一评估。

### 3.4 A2：时间平移的结果

本次结果中 A2 与 A0 的所有主要指标完全一致：迁移数均为 0，时延、成本、购电、碳排和新能源利用率均相同。这说明在当前初始信号和数据负荷下，外层贪心调度没有找到需要改变原始本地到达式执行方案的正向调度选择。

该现象与计划文档对常规场景的判断一致：当新能源供给整体宽松、边际供电成本大量接近 0 时，能源信号对任务调度的区分度有限，时间平移的边际收益会退化。A2 与 A0 相同并不意味着时间平移在所有场景下无价值，而是说明当前常规口径下“延迟任务以追踪能源信号”的收益不足以改变构造式调度结果。

### 3.5 A3：储能优化的贡献

A3 在固定 A2 任务方案的基础上引入区域储能 LP，结果改善明显：

- 运行成本从 -419,793,343.27 CNY 降至 -459,195,912.69 CNY，改善约 39,402,569.43 CNY。
- 购电量从 31.60 MWh 降至 0 MWh。
- 碳排从 8.85 tCO₂ 降至 0。
- 新能源外送量增加到 1,491,607.14 MWh。
- 新能源利用率由 67.91% 提升到 69.51%。
- 峰值净购电降至 0 MW。

因此，在本数据集上，储能是最明确、最稳定的成本和碳排改善来源。其核心作用不是改变任务执行方案，而是在新能源富余时充电、在新能源不足时放电，将时序上的新能源供需错配转化为可消除的储能调度问题。

### 3.6 A4：完整联合反馈的边际贡献

A4 在 A3 的基础上执行任务调度与能源 LP 的双向反馈。最终结果为：

- 仅有 27 个任务相对于本地方案发生迁移。
- 加权平均时延为 5.023 ms，最大时延为 25 ms。
- 购电量和碳排仍为 0。
- 运行成本进一步降至 -459,304,940.51 CNY。
- 相比 A3，目标值额外改善约 109,027.82 CNY。
- 外送新能源增加约 565.25 MWh。
- 新能源利用率保持在约 69.51%，数值上略低于 A3 的四舍五入显示值，但外送量和经济目标均有改善。

A4 的迁移规模很小，说明常规场景下外层影子价格信号大部分时间退化为低值或零值，任务重新布局的必要性有限。联合优化的主要价值体现在少量关键任务的微调：通过改变局部负荷时段或区域归属，进一步降低储能系统的弃电和能源机会成本。

## 4. A4 反馈收敛分析

A4 在第 2 轮达到收敛：

| 反馈轮次 | 目标值/CNY | 计划任务数 | 信号均值 | 相对变化 |
|---|---:|---:|---:|---:|
| 1 | -459,195,912.69 | 50,000 | 0.0000 | — |
| 2 | -459,304,940.51 | 50,000 | 1.8445 | 0.000237376 |

收敛判据为：

\[
\frac{|Obj^{(k)}-Obj^{(k-1)}|}{|Obj^{(k)}|}<10^{-3}.
\]

第 2 轮相对变化为 0.000237376，小于 0.001，因此停止反馈。该结果表明：

1. 第 1 轮能源 LP 基于初始能源信号得到完整可行调度；
2. 内层返回影子价格后，第 2 轮仅对少量任务进行重新安排；
3. 重新求解能源 LP 后目标值继续改善；
4. 改善幅度已低于预设收敛阈值，无需继续执行第 3 轮。

这与计划文档中“通常 2–4 轮稳定”的预期一致。

## 5. 敏感性分析

本次共完成 16 个场景：6 个碳价 λ 场景、6 个新能源利用上限 α 场景、3 个储能容量倍率场景和 1 个新能源下移 20% 场景。

### 5.1 碳价 λ 敏感性

λ 取 0、50、100、200、300、500 CNY/tCO₂ 时，所有主要结果完全一致：

- 任务数均为 50,000；迁移数均为 27；
- 目标值均为 -459,304,940.51 CNY；
- 购电量均为 0 MWh；
- 碳排均为 0 tCO₂；
- 新能源利用率均为 69.51%。

原因是常规场景下储能优化已经把购电和碳排降至 0，λ 无法进一步改变碳排结果。因此 λ 扫描在当前宽松场景下退化为同一点，不能单独展示成本—碳排权衡；必须结合 α 收紧或新能源下移压力场景分析碳价效果。

### 5.2 可再生能源利用上限 α 敏感性

| α | 迁移数 | 运行成本/CNY | 碳排/tCO₂ | 目标值/CNY | 购电/MWh | 峰值净购电/MW | 新能源利用率 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 0.5 | 0 | 274,665,413.00 | 463,901.57 | 367,445,726.94 | 1,053,877.52 | 462.03 | 49.88% |
| 0.6 | 0 | -25,036,653.04 | 223,128.61 | 19,589,068.05 | 531,008.89 | 367.10 | 56.85% |
| 0.7 | 0 | -270,415,632.84 | 56,601.51 | -259,095,330.14 | 136,033.70 | 221.36 | 63.10% |
| 0.8 | 0 | -395,939,472.01 | 69.91 | -395,925,489.53 | 112.33 | 43.74 | 67.01% |
| 0.9 | 66 | -440,486,059.98 | 0.00 | -440,486,059.98 | 0.00 | 0.00 | 68.80% |
| 1.0 | 27 | -459,304,940.51 | 0.00 | -459,304,940.51 | 0.00 | 0.00 | 69.51% |

α 是本次敏感性分析中最能体现联合模型压力响应的参数：

- α 从 1.0 降至 0.9 时仍可通过储能维持零购电、零碳排，但目标值恶化约 18.82 million CNY。
- α 降至 0.8 后，系统开始出现购电和碳排，购电量为 112.33 MWh，碳排为 69.91 tCO₂。
- α 降至 0.7，购电量增加到 136,033.70 MWh，碳排增加到 56,601.51 tCO₂。
- α 降至 0.5，购电量达到 1,053,877.52 MWh，碳排达到 463,901.57 tCO₂，目标值转为正值。

这说明储能并不能完全抵消新能源利用上限收紧造成的供能缺口。当 α 低于某一临界区间后，系统由“新能源—储能主导”切换为“购电—碳排主导”，成本和碳排会非线性上升。

### 5.3 储能容量倍率敏感性

| 储能容量倍率 | 迁移数 | 运行成本/CNY | 购电/MWh | 碳排/tCO₂ | 外送/MWh | 新能源利用率 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.5 | 25 | -448,991,439.11 | 0.00 | 0.00 | 1,440,455.54 | 69.00% |
| 1.0 | 27 | -459,304,940.51 | 0.00 | 0.00 | 1,492,172.39 | 69.51% |
| 2.0 | 5 | -459,319,401.55 | 0.00 | 0.00 | 1,492,225.87 | 69.52% |

储能容量从基准扩大到 2 倍后，目标值仅比基准进一步改善约 14,461.03 CNY，说明基准容量已经能够覆盖大部分新能源时序错配，继续扩容的边际收益很小。

容量缩减到 0.5 倍时仍保持零购电、零碳排，但目标值恶化约 10.31 million CNY，外送量减少约 51,716.85 MWh。由此可见，容量不足首先表现为储能套利能力和新能源消纳能力下降，达到更严重的压力程度后才会转化为明显购电和碳排。

### 5.4 新能源下移 20% 场景

在 `AvailableRenewable_MW × 0.8` 场景下：

- 任务数仍为 50,000；迁移数为 24；
- 加权平均时延为 5.034 ms，最大时延为 65 ms；
- 运行成本为 -395,925,633.80 CNY；
- 购电量为 385.10 MWh；
- 碳排为 182.46 tCO₂；
- 目标值为 -395,889,142.10 CNY；
- 新能源利用率提高到 83.68%。

新能源总量下移后，系统仍可通过储能和少量购电保持任务全量完成，但零购电、零碳排状态被打破。新能源利用率上升并不表示系统绝对表现变好，而是因为可利用新能源总量下降后，实际消纳量占剩余可用新能源的比例提高；评价时应同时关注购电量、碳排和弃电量。

## 6. 主要结论

### 6.1 储能是当前数据集的主导收益来源

A2 到 A3 的能源侧改造带来约 39.40 million CNY 的目标改善，并消除了全部购电和碳排。相比之下，A3 到 A4 的任务—能源反馈只带来约 109 thousand CNY 的边际改善。这说明当前数据的主要矛盾是新能源时序波动与负荷之间的错配，而不是任务区域迁移本身。

### 6.2 常规场景下边际供电成本信号存在退化

A4 仅迁移 27 个任务，且 λ=0–500 的结果完全一致。原因是常规 α=1.0 场景下储能可以使系统实现零购电、零碳排，大部分小时的边际供电成本为 0 或接近 0。此时外层任务调度对能源信号不敏感，联合优化的额外调度动作自然较少。

### 6.3 压力场景才真正激活联合优化

α 收紧和新能源下移会引入购电、碳排以及区域峰值压力，使能源影子价格不再退化。此时任务的区域选择和时间选择会影响储能 SOC、购电上限和弃电量，任务调度与能源调度之间的耦合明显增强。

### 6.4 迁移不能只看平均电价

A1 虽然迁移了 26,616 个任务，但在统一能源 LP 口径下成本和碳排均高于 A0。这说明迁移决策必须同时考虑：

- 逐时新能源供给；
- 储能充放电状态；
- 区域购电上限；
- IT 功率与 GPU 容量；
- 网络时延代价；
- 任务的到达与截止窗口。

单独依据区域平均电价或平均碳强度进行迁移，可能把负荷推向不利时段，反而增加系统能源成本。

### 6.5 储能扩容存在明显边际递减

容量减半会造成明显的目标恶化，但容量加倍只带来约 14.46 thousand CNY 的进一步改善，表明基准容量已经接近当前负荷与新能源曲线下的有效配置区间。后续若要继续提高储能投资价值，应优先研究更严格的 α、更低的新能源出力或更高的任务负荷，而不是在当前宽松场景下单纯扩容。

## 7. 结果使用边界与后续分析建议

1. A0/A1/A2/A3/A4 的比较使用统一的任务和能源评价口径，便于进行模块归因；其中 A0–A2 是任务调度方案差异，A3/A4 进一步引入储能和反馈。
2. 成本为净运行成本，负值主要来自新能源外送收入，不能直接解释为传统意义上的电费支出。
3. λ 扫描在 α=1.0 常规场景下退化，论文或正式报告中应重点展示 α≤0.8 和新能源下移 20% 的结果。
4. A1 的迁移规模较大但经济结果不优，说明当前构造式调度更适合被解释为约束可行性与迁移代价的基准方案，而不是最优迁移收益方案。
5. 本次完整运行使用 8 个 worker 并行执行独立方案和敏感性场景；并行只改变执行方式，不减少任务、不减少敏感性场景、不改变 LP 约束和反馈收敛条件。
