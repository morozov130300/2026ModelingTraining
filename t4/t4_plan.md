# 问题四建模框架（多区域"算-储-电"联合优化）

## 0. 赛题原文与"联合"原则

问题四要求在问题一至问题三的基础上，把任务迁移、电价机制、碳强度、新能源动态出力、储能充放电、区域购售电边界、网络时延与任务异构性**纳入统一框架**联合优化，并考察碳约束收紧、电价波动机制、新能源极端波动三类情景下的策略演变。

**必须与"串行优化"划清界限**：不能把问题二的任务方案直接喂给问题三的储能模型就声称"联合"——那是任务确定后储能被动适应的串行过程。联合优化的本质是**双向反馈**：

```text
任务改变负荷 → 负荷改变储能策略 → 储能改变边际供电成本 → 边际成本反哺任务调度
```

本框架采用已拍板的两层分解结构（Benders 型）：
- **外层**：整数任务调度（区域指派 + 开工时刻），滚动时域；
- **内层**：6 区域 × 2407 小时储能/能源 LP（完全复用问题三模型），对外层给定的负荷分布返回精确的能源成本、碳排、峰值与**边际供电成本**。

## 1. 关键数据事实（前三问已实测，决定联合结构）

### 1.1 任务侧（问题一/二结论）
- 50000 任务：实时推理 16724 / 批量推理 16717 / AI 训练 16559；
- 训练任务 GPU-hour 占 80.14%、AI IT 能耗占 87.12%——是唯一值得大规模迁移/平移的柔性负荷；
- 功率映射 0.08 / 0.10 / 0.16 MW/GPU；时延按类型恒等：RT 20 / BI 80 / AT 150 ms；
- 电价 A 708.1 → E 373.7（低 47%）；碳强度 A 0.62 → E 0.22（低 65%）；RegionE PUE 最低、RegionD GPU 容量最大。

### 1.2 能源侧（问题三结论）
- **可再生六区域逐时完全相同**（min=500、mean≈800、max=1100 MW）——空间维度不存在"绿电富集区"差异，"追绿电"只能体现在**时间维度**（日内 500↔1100 波动）；
- 给定负荷下 `R < TL` 仅 F 区 1 小时（缺口 31.6 MW）；可再生优先+储能即可实现**零购电、零碳排、零峰值净购电**（λ=0–500 结果一致）；
- 储能：A 350 / B 320 / C 300 / D 900 / E 820 / F 850 MWh，InitialSOC=45%、MinSOC=10%，ηc/ηd 0.93–0.94 / 0.92–0.93；SellLimit D 180 / E 220 / F 220（A/B/C=0）；
- **MaxGridImport（购电上限）**：A 550 / B 520 / C 510 / D 510 / E 370 / F 340 MW——这是问题四最关键的新咬合约束：问题三给定负荷下 A/B/C 设施峰值（554/531/537）已超过各自购电上限，靠可再生覆盖；问题四任务重排后此约束会真实起作用；
- 问题三储能边际贡献：成本 −39,385,683.90 元、购电 −31.60 MWh、弃电 −184,764.12 MWh、利用率 67.91%→69.51%；
- 压力场景已验证：可再生下移 20%（`R×0.8, α=1.0`）时购电与碳排重新出现（购电 112.33 MWh、碳排 69.91 tCO2 于 α=0.8 等价口径；α 收紧至 0.5 时购电 105 万 MWh、碳排 46.4 万 tCO2）。

### 1.3 三条数据事实对联合结构的决定性影响
1. **空间套利靠电价/碳强度/PUE，不靠绿电**——任务迁移的目标是低价低碳低 PUE 区域（D/E/F），时间平移的目标才是追新能源曲线；
2. **宽松场景下成本—碳排权衡退化**（零购电零碳排可达），Pareto 前沿的重点是**成本 vs 时延**与**成本 vs 区域峰值**；碳类权衡只在压力场景（α 收紧/可再生下移）出现；
3. **联合增量来自 GPU 容量 ↔ 购电上限 ↔ SOC 三约束耦合**：储能放电成为"临时算力通道"，让训练任务在 GPU 空闲但能源紧张的时段照常运行，反之任务时间/空间平移本身就在为负荷削峰、减轻储能压力。

## 2. 官方口径（与问题二/三统一）

- 成本 `C = Σ(GridPurchase×ρ − GridSell×φ)`（毛购电口径，同问题三）；
- 碳排 `E = Σ(GridPurchase×ξ)`（按购电，非净购电）；
- 能源平衡 `GridPurchase + AvailableRenewable + Discharge = Total_Load + Charge + GridSell + Curtailment`；
- SOC 递推与终端 `SOC(2406) ≥ InitialSOC`，**第 2406 小时充放=0**（问题三已拍板）；
- 利用率 `(直接消纳 + 新能源充电 + 外送)/可用`（含充电项）；
- 购售电边界 `GridPurchase ≤ MaxGridImport`、`GridSell ≤ SellLimit`（区域级硬约束）；
- 任务口径（问题一/二）：整数小时开工 + 分钟级重叠折算 GPU-hour；时延按类型恒等；实时任务"约束开放、解本地化"。

## 3. 模型（两层分解）

### 3.1 外层：整数任务调度（滚动时域）

**决策变量**
- `x(i,r) ∈ {0,1}`：任务 i 指派到区域 r；
- `τ(i) ∈ ℤ`：任务 i 开工小时（整数，同问题一/二口径）。

**候选集剪枝（求解前完成）**
- 时延剪枝：RT 仅局部候选（20ms 矩阵）、BI 中尺度（80ms）、AT 大范围（150ms）——复用问题二三级柔性结论；
- 时刻剪枝：`τ(i) ≥ arrival`、`τ(i) + dur ≤ deadline`；
- 容量粗筛：区域剩余 GPU 明显不足的任务候选剔除。

**约束**
- 每任务恰好执行一次且不可拆分、不可抢占：`Σ_r x(i,r) = 1`，执行连续性由开工时刻+时长保证；
- 实时推理：到达即开工、本地执行（Q1 拍板的选项 C，不参与迁移优化）；
- 区域容量：逐小时 `Σ_i x(i,r)·g_i·overlap(i,t,τ) ≤ GPU_cap(r)`（分钟重叠折算）；
- 区域功率：IT 功率 `Σ_i x(i,r)·p_i·overlap ≤ IT_power_cap(r)`、设施功率乘 PUE 后再约束；
- 能源边界：由内层 LP 承载（购电上限、SOC、外送），外层不重复硬约束，只接收内层返回的不可行信号并回退。

**目标（单目标，已拍板）**
```text
min Σ_i EnergyCostSignal(i, r, τ(i))
```
其中 `EnergyCostSignal` 由内层 LP 返回的**边际供电成本**（该区域该小时的影子价格 × 任务功率 × 时长）+ 迁移罚项构成；λ×碳排已并入内层目标，不在此重复。

**滚动时域**：每步取"已到达未执行任务 + 未来 N 小时能源信号（电价/可再生/碳强度/SOC 轨迹）"，决定窗口首段已确定决策后推进。50000 任务按到达时间分批，每批规模受外层算法限制。

### 3.2 内层：能源 LP 子问题（复用问题三模型）

给定外层负荷分布 `Total_Load(r,t)`（任务 IT × PUE + 非 AI 负荷）后，对 6 区域独立求解 2407 小时 LP：

- 变量：`cR/cG/d/q/y/s/u/w`（同问题三 §3.1）；
- 约束：能源平衡、SOC 递推与上下限、终端 SOC、2406 充放=0、充放/购电/外送上限、`GridCharge ≤ GridPurchase`、可再生守恒 `u+cR+y+w=R`、消纳上限 `u+cR+y ≤ α·R`、`NetGridImport ≤ MaxGridImport`；
- 目标：`min Σ(q×ρ − y×φ) + λ·Σ(q×ξ)`；
- **返回给外层**：总成本、碳排、峰值净购电、利用率、外送收入，以及各区域逐时**边际供电成本**（负荷平衡约束的 Lagrange 乘子/影子价格）。

### 3.3 反馈与收敛

```text
第 k 轮：外层按边际成本信号 M^(k-1) 重排任务 → 内层 LP 求 M^(k)（新影子价格）
收敛判据：|Obj^(k) − Obj^(k-1)| / |Obj^(k)| < ε（建议 ε=1e-3），通常 2–4 轮稳定
```

**必须诚实处理的退化**：宽松场景（可再生优先下零购电可达）中，多数时段边际供电成本≈0（可再生免费、购电为 0），反馈信号接近零、外层对能源信号不敏感——此时联合与"任务层能源单价 + 储能后处理"差异很小。**联合价值的真实体现依赖压力场景**（α 收紧、可再生下移 20%、负荷堆叠触发购电上限），写作时应主动说明"常规场景信号退化、压力场景信号激活"的机制，这本身是很好的分析点。

## 4. 归因与对比结构（消融 A0–A4）

统一用问题四的能源 LP 口径评估各方案（避免各问口径不一致），逐项差即各模块贡献：

| 方案 | 内容 | 隔离出的贡献 |
|---|---|---|
| A0 | 纯本地、到达即执行、无储能（问题一口径） | 起点（纯算力基准的能源后果） |
| A1 | A0 + 跨区域迁移（问题二方案 B） | **空间套利**：电价/碳强度/PUE 差 |
| A2 | A1 + 时间平移（延迟到低价低碳时刻） | **时间套利**：追新能源/电价时刻 |
| A3 | A2 基础上任务固定 + 储能优化（问题三口径） | **能源时间套利**：弃电→外送/补缺 |
| A4 | 全联合（本框架两层结构） | **协同收益**：GPU↔购电上限↔SOC 耦合 |

预期结构：A1、A2 贡献主要部分（任务侧），A3 贡献其次（问题三已测 39.4M 元），A4 为边际增量——若 A4 增量过小，恰说明常规场景信号退化，需用压力场景展示联合必要性。

## 5. Pareto 分析

**扫描维度**（均为已定口径的参数扫描）：
- λ（碳价）0–500：宽松场景下结果一致（零购电零碳排），前沿退化为竖线——报告需说明并转向压力场景；
- α（可再生利用上限）0.5–1.0：α 收紧后购电/碳排出现，**成本—碳排前沿在此有效**；
- 储能容量 ×0.5–2.0：价值—容量曲线（问题三已测扩容边际收益仅 13.5 万元，问题四负荷可动后可能不同）。

**重点前沿**（本数据下最有辨识度）：
1. **成本 vs 最大/加权时延**：迁移越远越便宜、实时任务时延越接近 SLA 上限（GPU-hour 加权口径，同问题二）；
2. **成本 vs 区域峰值**（GPU 峰值与净购电峰值）：低价区域不能无限堆任务；
3. **成本 vs 碳排**：仅在压力场景（α≤0.7、可再生下移）呈现非平凡形态。

输出为多组"低成本型 / 低碳型 / 均衡型"代表性方案，供决策讨论。

## 6. 三类情景分析（题目要求）

1. **碳约束收紧**：λ 提高 + α 收紧组合——预期训练任务向低碳区域（E/F）进一步迁移、高碳购电时段减少、成本上升；只有在购电重新出现的压力口径下才有可量化效果；
2. **电价波动机制**：峰谷价差放大 → 任务延迟价值与储能套利价值上升（更多柔性任务等低价时段、储能充放加深）；价差缩小 → 时间维度套利意义下降，空间迁移权重上升；
3. **新能源波动增强**：可再生下移 20%（**已测口径**：`R×0.8, α=1.0`，与 α=0.8 可行域等价，报告需注明口径）+ 可选方差放大场景——储能重要性上升、系统需保留更多 SOC 裕度、"追新能源"难度增加。

## 8. 论文结构与创新点

结构：问题重述与"联合 vs 串行"辨析 → 数据事实（空间/时间/能源时间三种灵活性的量化基础）→ 两层模型（外层整数任务 + 内层 LP + 边际成本反馈）→ 消融归因 → Pareto → 三情景 → 结论。

创新点建议（不写"采用了某某算法"）：
- **两层分解联合优化**：外层滚动任务调度 + 内层全局精确 LP，Benders 型反馈而非启发式三层拼装，收敛可验证；
- **边际供电成本反馈机制**：把"任务↔储能"的双向影响落实为影子价格信号，并诚实刻画其在宽松场景的退化与压力场景的激活；
- **消融归因**：空间/时间/能源时间三种灵活性逐项分离，量化协同增量；
- **压力场景承接**：问题三已验证的 α 收紧与可再生下移 20% 直接作为问题四碳情景与极端波动情景的载体，全题逻辑闭环。

## 9. 决策记录与剩余待定点

**已拍板**：
1. **两层结构**（Benders 型）：外层整数任务调度（滚动时域）+ 内层 6×2407 小时能源 LP；
2. **单目标** `min 成本 + λ×碳排`，时延/SLA 与峰值作为约束处理，Pareto 由 λ/α/容量参数扫描生成（不用进化算法）；
3. **压力场景**：可再生下移 20%（`R×0.8, α=1.0`，与 α=0.8 可行域等价），已在问题三实测验证购电与碳排重新出现。

**剩余待定点**：
1. **滚动窗口长度**（建议 24–72h）与每步任务批规模（50000 任务分批的粒度）；
2. **外层任务调度算法**：贪心 + 局部搜索（推荐，规模可控）还是小型 MILP（只对窗口内任务，变量 ~窗口任务数×候选区域）；
3. **边际成本信号退化时的降级策略**：常规场景是否直接退化为"问题二能源单价 + 内层 LP 校核"，仅压力场景启用完整反馈循环（节省算力，论文需说明自适应切换）；
4. **时延目标的报告口径**：GPU-hour 加权平均与最大值并用（同问题二评价指标表）。

## 10. 与前三问的接口

- **问题一**：提供整数小时开工、分钟重叠折算、实时任务本地化等任务层口径与 GPU 容量数据；
- **问题二**：提供三级柔性候选集、迁移收益结构、任务层评价口径（时延/利用率）；
- **问题三**：提供能源 LP 的变量、约束、SOC 口径、归因框架（方案 1→2）与压力场景（α 收紧、可再生下移 20%）——问题四在**同一能源平衡与约束体系**中把任务负荷从"给定"改为"可调"，即问题四 = 问题二的任务决策 × 问题三的能源评估联合求解。
