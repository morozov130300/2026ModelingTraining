# 流感 A 辅助筛查研究 —— 问题 1 统计分析方案

> 前置输入：`数据预处理方案.md` 的产出物（data_merged.csv、数据字典、变换决策表、变量体检表）。
> 问题 1 边界：本阶段**不建立判别模型**，仅做数据深挖、分布/差异/关系分析、变量筛选分类评估。
> 模型定位声明：研究结果仅用于数学建模意义上的辅助筛查研究，不作为临床诊断依据。

---

## 1. 总体策略：一主一辅一对照

| 角色 | 框架 | 性质 | 作用 |
|---|---|---|---|
| **主框架** | 临床功能分组（氧气运输 / 免疫防御 / 凝血止血） | 假设驱动（演绎） | 报告主线：按功能维度组织全部统计分析 |
| **辅视角** | 参考区间异常模式 | 假设驱动（演绎） | 补充"临床医生视角"：看异常比例而非原始分布 |
| **对照框架** | 血象表型聚类 | 数据驱动（归纳） | 让数据自己找分组，与功能分组互证 |

两条独立证据线（文献告诉你怎么分 vs 数据告诉你怎么分）若收敛，报告说服力最强；若不收敛，如实报告差异，作为讨论素材。

## 2. 医学叙事框架（如何呈现医学内容）

**总原则：文献说 + 数据验。** 医学叙事以"可审计的假设"形式出现，不做无出处的自我断言。

### 2.1 假设-检验闭环表（主叙事格式）

| 功能组 | 指标 | 医学预期（附文献） | 统计检验 | 数据结果 | 结论 |
|---|---|---|---|---|---|
| 氧气运输 | RBC、HB | 同系统应强正相关 | Spearman r | （待填） | （支持/不支持） |
| 免疫防御 | WBC、N、L | 流感组淋巴细胞方向**不预设**，文献提示常见淋巴细胞降低 | Mann-Whitney + 效应量 | （待填） | （与文献一致/不符） |
| 免疫防御 | NLR | 右偏分布，判别力可能优于单一指标 | 单变量 AUC 对比 | （待填） | （支持/不支持） |
| 凝血止血 | PLT | 差异不预设 | Mann-Whitney + 效应量 | （待填） | （待结论） |

数据不支持的预期行**不要删**，标注"与预期不符，见讨论"——这本身是发现。

### 2.2 三级谨慎句式（结果回译的措辞纪律）

| 句式层级 | 示例 |
|---|---|
| 一级（数据陈述） | "流感组淋巴细胞中位数显著低于健康组（p<…）" |
| 二级（方向+文献限定） | "……该方向与文献中流感相关淋巴细胞降低的报道一致（[文献](https://pmc.ncbi.nlm.nih.gov/articles/PMC7246361/)）" |
| 三级（不越界） | 不写"淋巴细胞降低是流感 A 的特征"，写"在本研究样本中，该指标方向与文献报道一致，其机制解释超出本统计分析范围" |

### 2.3 逻辑型医学叙事（无需深度医学知识）

只用可验证的结构关系做叙事：同一功能系统 → 指标应相关（RBC-HB）；同源计数 → 冗余（WBC-N）；比值 → 信息压缩（NLR）。让相关矩阵替你说话。

## 3. 主框架：临床功能分组假设表

### 3.1 分组定义

| 功能组 | 指标 | 临床功能逻辑（附文献） |
|---|---|---|
| 氧气运输与贫血诊断组 | RBC、HB、RDW | HB 为贫血判断核心指标；RBC 辅助判断贫血类型；RDW 反映红细胞大小异质性，为辅助鉴别指标（StatPearls, CBC with Differential） |
| 免疫防御与感染鉴别组 | WBC、N、L、M | 白细胞分类计数反映免疫反应轴；临床常用 NLR 等组合指标辅助感染类型鉴别（Templeton et al., Br J Cancer 2015） |
| 凝血与止血组 | PLT | 血小板独立执行黏附、聚集、止血功能 |

### 3.2 可检验假设（预设方向仅限文献有据者，其余不预设）

1. H1（氧气组）：RBC 与 HB 在两组中均强正相关（|r| > 0.6）→ 验证分组逻辑
2. H2（氧气组）：两组 HB/RBC/RDW 的分布差异方向待检验（不预设贫血负荷方向）
3. H3（免疫组）：流感组 WBC、N 可能升高；**L 方向不预设**——文献提示流感常见淋巴细胞降低（而非教科书笼统的"病毒感染淋巴细胞升高"）
4. H4（免疫组）：NLR 的单变量判别能力可能高于单一指标 L 或 N
5. H5（凝血组）：两组 PLT 差异不预设
6. H6（结构）：WBC 与 N 绝对值高相关（冗余）→ 为特征去冗余提供依据

## 4. 板块一：分布特征展示

**目标**：让读者看到两组长什么样，按功能组组织。

- 逐指标按组小提琴图 / 箱线图+散点 / 密度曲线（8 项血液指标 + 年龄、性别）
- **按三个功能组各出一张分面图**（氧气组 3 格、免疫组 4 格、凝血组 1 格）
- 每个取 log 的指标附"原始 vs log 后"直方图对比（呼应预处理决策）
- 配套统计表：两组的中位数/IQR/偏度，偏态指标以中位数为主口径
- 免疫组加一张 **NLR 按组密度图（log 刻度）** 作为组合特征预览

**产出**：按功能组组织的分布图集 + 描述性统计表。

---

## 5. 板块二：差异特征检验

**目标**：用统计证据回答"两组哪些指标不同、差异多大"。

| 内容 | 方法 | 注意 |
|---|---|---|
| 连续变量主检验 | Mann-Whitney U（非正态口径） | 血检基本偏态，不以 t 检验为主 |
| 效应量 | Cliff's delta（或 rank-biserial r） | 报告差异大小，而非只报告有无差异 |
| 分类变量（性别等） | 卡方检验 | 同时报告构成比例 |
| 多重比较校正 | **组内 FDR + 全局 BH 双口径** | 组内校正更贴合"分组检验"逻辑 |
| 差异方向 | 两组中位数对比，标注 ↑ / ↓ | 不预设方向，由数据给出 |

**核心图**：效应量热图——行 = 变量（按功能组排列）、列 = 组别、颜色 = Cliff's delta 方向与大小。

**产出**：差异分析表（变量、两组中位数、原始 p、校正 p、效应量、方向）+ 效应量热图 + 每个功能组的"组级结论"句。

---

## 6. 板块三：变量间关系分析

**目标**：展示变量结构，验证分组逻辑，为特征去冗余提供依据。

1. **全样本 Spearman 相关矩阵热图**，用色块/边框圈出三个功能组的内部相关块
2. **组内相关专门验证**：RBC-HB、WBC-N 的相关系数；|r| > 0.6 视为支持分组逻辑（对应 H1、H6）
3. **分组相关矩阵对比**：流感组与健康组的相关结构并列展示，看是否因组而异（如流感组 WBC-N 相关更强）——"关系差异"本身是判别线索
4. **VIF 按功能组报告**：氧气组内部冗余（RBC-HB）、免疫组内部冗余（WBC-N）→ 为问题 2 "组内代表变量"选择提供依据
5. 可选加分项：层次聚类 / PCA 看变量自然分组（与板块四的样本聚类互为补充）

**产出**：相关热图（全样本 + 分组对比）+ 组内相关验证表 + VIF 表。

## 7. 板块四：关键信息综合评估（问题 1 交付物）

### 7.1 综合证据表（变量筛选分类评估）

| 变量 | 所属功能组 | 校正后 p | 效应量 | 单变量 AUC | 共线性备注 | 潜力评级 |
|---|---|---|---|---|---|---|
| … | … | … | … | … | … | 高/中/低 |

三个维度：**差异显著性（校正 p）+ 效应量 + 单变量 AUC**（单变量 AUC 为纯统计描述，不构成建模）。

叠加共线性备注：从高相关组内推荐代表变量。**最终"高潜力 + 代表变量"集合 = 问题 2 的特征初选集**。

### 7.2 组合指标评估（免疫组延伸）

构造 NLR = N/L（可选 MLR、PLR），对每个组合指标做：差异检验 + 单变量 AUC，并与单一指标对比。

**可交付结论**："组合指标是否优于单一指标"——若 NLR 的 AUC 高于 L 和 N 单独值，即为"组合信息压缩有效"的统计证据（对应 H4）。

### 7.3 两级结论

- **功能组层面**：哪个功能维度最能区分两类样本？（组内指标效应量均值 + 单变量 AUC 中位数）
- **变量层面**：综合证据表的评级结果 + 组合指标结论

**产出**：综合证据表 + 单变量 AUC 排序条形图（按功能组着色）+ 两级结论。

## 8. 辅视角：参考区间异常模式分析

**医学逻辑**：临床医生看病历看的是"哪几项飘红"——比较异常模式而非原始分布。

| 步骤 | 操作 |
|---|---|
| 8.1 参考区间来源 | 引用文献参考区间（CLSI C28-A3 方法学；[Omuse et al., PLOS One 2018](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0198444)），注明人群与实验室差异的局限 |
| 8.2 三分类编码 | 每个指标按参考区间编码为 正常/偏高/偏低 |
| 8.3 异常比例比较 | 各指标"超出参考区间比例"的两组比较（卡方 / Fisher 精确检验） |
| 8.4 异常计数比较 | 每个患者的异常指标个数，两组比较（Mann-Whitney U）——"整体血象异常负荷" |
| 8.5 异常模式 | 高频组合模式（如 WBC 偏高 + L 偏低）在两组的频次表 |

**定位**：与主框架正交的补充视角，工作量小（3 张表 + 1 张图），但显著丰富"临床医生视角"。

## 9. 对照框架：血象表型聚类分析（归纳线）

**目的**：不预设医学分组，让数据自己发现血象模式，与功能分组互证。

| 步骤 | 操作 |
|---|---|
| 9.1 数据准备 | 用预处理后的指标（log 变换 + 标准化，排除人口学变量或仅作辅助） |
| 9.2 聚类 | 层次聚类或 K-means（K 由轮廓系数确定）；可选 PCA 降维可视化 |
| 9.3 簇-组别交叉 | 各簇中流感组/健康组的构成比例（卡方 / 百分比） |
| 9.4 剖面回译 | 每个簇的指标均值剖面图 → 用三级谨慎句式描述该簇的血象特征 |
| 9.5 收敛性讨论 | 数据分出的簇是否对应功能分组的逻辑？收敛 → 互证；不收敛 → 讨论差异原因 |

**定位**：不需要任何医学知识即可执行，却反过来验证你的医学分组是否被数据支持——方法学亮点所在。

## 10. 影响说明章节（问题要求明示）

预处理阶段的每个决策对后续分析/建模的影响，集中成表格 + 一段文字：

| 预处理决策 | 对后续分析/建模的影响 |
|---|---|
| 单位/格式统一 | 统计检验与模型系数有可比意义 |
| 异常值保留 + log 变换 | 中位数/IQR 稳健；检验更可靠；进入逻辑回归时系数不被个别大值主导 |
| 缺失保留 + 指示变量 | 保留"未检查"这一潜在判别信息，避免小样本进一步缩水 |
| 样本量差异 | 小样本侧检验功效受限：显著但效应量小的结果谨慎解读；关键指标的中位数差配 bootstrap 置信区间；建模时 EPV 按少数类计 |
| 不重采样 | 避免人为扭曲分布；以 EPV 约束特征数为补偿 |
| log 口径 | 解释系数时需换算回原始刻度或按 log 单位表述 |

**局限性段落**：参考区间的来源差异、样本量与人群代表性、谱系（流感 vs 健康）限制——均如实声明。

## 13. 分析纪律

1. **全程不建模**：单变量 AUC、Hotelling T²（如使用）均为统计描述，不训练任何分类器
2. **不预设方向**：尤其淋巴细胞，由数据给出方向，仅与文献做"一致/不符"对照
3. **医学叙事三要素**：每句临床解读 = 数据结果 + 方向 + 文献限定
4. **可复现**：每张图、每张表对应可运行代码与编号
5. **口径统一**：log 变换指标统一命名（如 `log_WBC`），原始与变换后分别报告
