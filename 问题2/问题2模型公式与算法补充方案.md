## 1. 数据与预处理记号

问题 1 确定的预处理口径沿用至建模：

- 计数型指标（WBC、N、L、M、PLT）在预处理阶段已做 Box-Cox 变换近似正态，变换后变量记为 $\tilde{x}$；脚本从预处理结果直接读取变换后数值，**不再重复变换**；
- 组合指标 NLR = N/L 取对数：$\mathrm{NLR\_log}=\ln(1+\mathrm{NLR})$，MLR_log、PLR_log 同理；
- 年龄：原始尺度，不做变换；
- 所有连续变量在进入弹性网/LDA/SVM 前做标准化（零均值、单位方差），记标准化后为 $z_j=(x_j-\hat\mu_j)/\hat\sigma_j$；
- 特征集由问题 1 综合证据表预指定（EPV=10 约束，$p\le 5$），**CV 内不做特征选择，仅调参**，避免选择泄漏。

**各变量进入模型的实际尺度汇总**：

| 变量 | 预处理变换 | 模型输入尺度 |
|---|---|---|
| L | Box-Cox | 标准化 $z$ |
| M | Box-Cox | 标准化 $z$ |
| N | Box-Cox | 标准化 $z$ |
| 年龄 | 无 | 标准化 $z$ |
| NLR_log | $\ln(1+\mathrm{NLR})$ | 标准化 $z$ |
| PLT | Box-Cox | 标准化 $z$ |

## 2. 弹性网逻辑回归（主模型）

### 2.1 模型形式

设 $\pi_i=P(y_i=1\mid\mathbf{x}_i)$，逻辑回归假设：

$$
\log\frac{\pi_i}{1-\pi_i}=\beta_0+\mathbf{x}_i^{\top}\boldsymbol{\beta}
\qquad\Longleftrightarrow\qquad
\pi_i=\frac{1}{1+\exp\left(-\left(\beta_0+\mathbf{x}_i^{\top}\boldsymbol{\beta}\right)\right)}
$$

### 2.2 参数估计：弹性网惩罚似然

最大化带弹性网惩罚的对数似然（等价于最小化）：

$$
\hat{\boldsymbol{\beta}}(\lambda,\alpha)=\arg\min_{\beta_0,\boldsymbol{\beta}}\left\{
-\frac{1}{n}\sum_{i=1}^{n}\left[y_i\ln\pi_i+(1-y_i)\ln(1-\pi_i)\right]
+\lambda\left(\alpha\|\boldsymbol{\beta}\|_1+\frac{1-\alpha}{2}\|\boldsymbol{\beta}\|_2^2\right)
\right\}
$$

其中 $\|\boldsymbol{\beta}\|_1=\sum_j|\beta_j|$，$\|\boldsymbol{\beta}\|_2^2=\sum_j\beta_j^2$；$\alpha\in[0,1]$ 控制 L1/L2 比例，$\lambda\ge0$ 控制收缩强度。

**本报告取 $\alpha=0.5$ 固定**（阶段一已用统计方法压缩特征至 $p\le5$，L1 的"特征选择"作用大部分已完成，弹性网在此主要提供 L2 收缩以稳定系数），$\lambda$ 由嵌套 CV 内层确定。求解采用坐标下降法（glmnet 算法族）。

### 2.3 本数据最终模型（含年龄版）

$$
\log\frac{\pi}{1-\pi}=
5.5080-1.6194\,L+4.2960\,M-0.4818\,N-0.0829\,\mathrm{年龄}+1.9607\,\mathrm{NLR\_log}
$$

> 注：系数在标准化尺度上估计，解释 OR 时需注意尺度（见第 7 节）。OR 表（报告 §8.1）来自 2000 次 Bootstrap 重采样（每次重采样后重新标准化拟合），与本节全数据标准化系数的 exp 值口径不同，因此 exp(本节系数) 与 OR 表数值存在差异。

## 3. LDA（线性判别分析）

### 3.1 模型假设与判别函数

假设两组服从多元正态分布、协方差矩阵相同（$\mathbf{\Sigma}_0=\mathbf{\Sigma}_1=\mathbf{\Sigma}$），则判别函数为：

$$
\delta_k(\mathbf{x})=\mathbf{x}^{\top}\mathbf{\Sigma}^{-1}\boldsymbol{\mu}_k-\frac{1}{2}\boldsymbol{\mu}_k^{\top}\mathbf{\Sigma}^{-1}\boldsymbol{\mu}_k+\ln\pi_k,\qquad k\in\{0,1\}
$$

分类规则：$\hat{y}=\arg\max_k\delta_k(\mathbf{x})$。

### 3.2 二分类等价形式（Fisher 判别得分）

对两类问题，等价于一个线性得分 $S(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x}+w_0$，其中 $\mathbf{w}\propto\mathbf{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$；$\boldsymbol{\mu}_k$、$\mathbf{\Sigma}$ 由样本估计。判别得分 $S$ 的分布图即报告中的"LDA 判别得分图"。

## 4. CART（分类回归树，深度 ≤3）

### 4.1 分裂准则（Gini 不纯度）

节点 $t$ 的不纯度：$\mathrm{Gini}(t)=1-\sum_{k}p(k\mid t)^2$，其中 $p(k\mid t)$ 为节点 $t$ 中类别 $k$ 的比例。

对候选分裂 $s$，选择使不纯度下降最大的分裂：

$$
\max_s\ \Delta(s)=\mathrm{Gini}(t)-\left[\frac{n_{t_L}}{n_t}\mathrm{Gini}(t_L)+\frac{n_{t_R}}{n_t}\mathrm{Gini}(t_R)\right]
$$

### 4.2 停止准则

- 最大深度 ≤3（预设，控制复杂度、保证可解释）；
- 叶节点最小样本数设下限（如 ≥20）；
- 不做后剪枝，以深度约束 + 嵌套 CV 评价为准。

### 4.3 预测

新样本沿树路径落入叶节点，输出该叶节点的经验类别概率 $\hat{p}=n_{k,\text{leaf}}/n_{\text{leaf}}$。

## 5. SVM-RBF（灵活对照）

### 5.1 决策函数

RBF 核 $K(\mathbf{x}_i,\mathbf{x}_j)=\exp\left(-\gamma\|\mathbf{x}_i-\mathbf{x}_j\|^2\right)$，决策函数：

$$
f(\mathbf{x})=\sum_{i\in SV}\alpha_i y_i K(\mathbf{x}_i,\mathbf{x})+\hat{b}
$$

$SV$ 为支持向量集；$\alpha_i$ 由对偶二次规划求解，$\gamma$ 与正则化参数 $C$ 由嵌套 CV 内层网格搜索确定。

### 5.2 概率输出（Platt 缩放）

SVM 原始输出 $f(\mathbf{x})$ 非概率，经 Platt 缩放映射为概率：

$$
P(y=1\mid\mathbf{x})=\frac{1}{1+\exp\left(A f(\mathbf{x})+B\right)}
$$

$A,B$ 由交叉验证最小化对数损失估计。

> 注意：SVM 无似然框架，**不适用 AIC/BIC 比较**；其"Log-Likelihood"仅为 Platt 缩放下的伪似然，不与逻辑回归类模型的 AIC/BIC 直接可比。

## 6. 评价指标公式

| 指标 | 公式/定义 |
|---|---|
| AUC | $\mathrm{AUC}=P(S_1>S_0)=\dfrac{U}{n_1 n_0}$（$U$ 为两组预测得分排名的 Mann-Whitney 统计量） |
| PR-AUC | 精确率-召回率曲线下面积；不平衡数据下反映正类检索能力 |
| Brier | $\mathrm{Brier}=\dfrac{1}{n}\sum_{i=1}^{n}(y_i-\hat{p}_i)^2$，越低校准越好 |
| 灵敏度 | $\mathrm{Se}=\dfrac{TP}{TP+FN}$；特异度 $\mathrm{Sp}=\dfrac{TN}{TN+FP}$ |
| F1 | $F_1=\dfrac{2\cdot \mathrm{Precision}\cdot \mathrm{Se}}{\mathrm{Precision}+\mathrm{Se}}$ |
| PPV/NPV | 阳性/阴性预测值，依赖筛查人群患病率 |
| AIC/BIC | $\mathrm{AIC}=-2\ln L+2k$；$\mathrm{BIC}=-2\ln L+k\ln n$（$k$ 为参数个数，仅适用于基于似然的模型） |
| HL 检验 | 按预测概率十分位分 $G$ 组：$\chi^2=\sum_{g=1}^{G}\dfrac{(O_g-E_g)^2}{E_g(1-\bar{p}_g)}$；极端不平衡/预测概率接近 0-1 时该检验不可靠，以 Brier 与校准曲线为准 |
| DeLong 检验 | 对同一批样本上两个模型的 AUC 差做 U 统计量检验，给出 $\Delta AUC$ 的 $z$ 与 $p$ |

## 7. 验证与校正算法（伪代码）

### 7.1 分层重复 k 折交叉验证

```
输入：数据 D，模型 M，重复次数 R，折数 K
输出：OOF 预测概率、AUC 均值±SD
for r in 1..R:
    对 D 按标签分层分成 K 折
    for k in 1..K:
        训练集 = D \ fold_k，测试集 = fold_k
        在训练集上拟合 M（调参仅在训练集内进行，见 7.2）
        预测 fold_k，收集 OOF 概率
计算每折 AUC，报告 R×K 次结果的均值±SD
```

### 7.2 嵌套交叉验证（调参防泄漏）

```
外层折外循环:
    内层（仅用外层训练集）:
        λ ∈ 网格, 内层再分层 CV 选最优 λ*
    用 λ* 在外层训练集重拟合，预测外层测试折
```

### 7.3 Bootstrap 乐观度校正（Efron）

```
1. 在原始数据 D 上拟合模型，计算表观性能 AUC_app
2. for b in 1..2000:
    有放回抽样得 D*_b（与 D 等容）
    在 D*_b 上拟合，评估 D*_b 得 AUC_boot_in
    同模型评估原始 D 得 AUC_boot_orig
    optimism_b = AUC_boot_in − AUC_boot_orig
3. 乐观度 = mean(optimism_b)
4. 校正后 AUC = AUC_app − 乐观度
```

> 本数据结果：弹性网乐观度 0.0012（校正后 0.9889），CART 乐观度 0.0246（校正后 0.9513）——弹性网对样本依赖度远低于树模型。

### 7.4 留一法（LOOCV）

每次留一个样本做测试，其余 $n-1$ 个训练，共 $n$ 次，计算 AUC（小样本下的保守口径）。

## 8. 评分卡构造算法（问题 3 接口）

1. **取系数**：最终弹性网模型系数 $\hat{\beta}_0,\hat{\beta}_1,\dots,\hat{\beta}_p$（标准化尺度）
2. **分箱**：每个连续变量按三分位数分 3 档（在原始尺度上分箱，保持分档可解释性）
3. **赋分**：第 $j$ 变量第 $b$ 档得分 $s_{j,b}=\hat{\beta}_j\cdot(\bar{z}_{j,b}-\bar{z}_j)$，其中 $\bar{z}_{j,b}$ 为该箱内标准化后特征均值，$\bar{z}_j$ 为全样本标准化后特征均值（标准化后 $\bar{z}_j \approx 0$）
4. **总分**：$S=\hat{\beta}_0+\sum_{j,b}s_{j,b}$；分数越高，$\hat{p}$ 越高（因 $\hat{p}$ 随 $\logit$ 单调）
5. **阈值**：按目标灵敏度（0.90/0.95）在总分分布上确定截断点

> 报告评分卡中的"原始分"即为 $\hat{\beta}_j\cdot(\bar{z}_{j,b}-\bar{z}_j)$，在标准化尺度上计算。由于 $\bar{z}_j \approx 0$，原始分近似为 $\hat{\beta}_j\cdot\bar{z}_{j,b}$。

## 9. 阈值选择算法（筛查场景）

```
目标：给定目标灵敏度 Se*（0.90 / 0.95）
1. 在 OOF 预测概率上，对候选阈值 t ∈ (0,1) 网格：
    计算 Se(t)、Sp(t)
2. 取满足 Se(t) ≥ Se* 的最大 t 作为操作点
3. 报告该点的 Se、Sp、PPV、NPV
注：若数据/模型最大可达灵敏度低于 Se*，应如实说明（见 E5 修正）
```

## 10. 模型公式与系数方向的尺度说明（可解释性）

- **OR 的尺度**：逻辑回归 OR 为"每增加 1 个（变换/标准化）单位"的风险倍数。如 $M$ 的 OR≈81 表示变换尺度上 M 增加 1 单位；而 M 原始中位数仅 0.66 ×10⁹/L，实际可解释变化远小于 1 单位——报告应同时给出标准化 OR 或"每 1 个 SD 增加"的 OR
- **N 方向翻转**：Q1 中 N 边际效应为正向（N 高→流感），而多变量模型中 N 系数为负（OR 0.670）。原因是 N 与 NLR_log 高度相关（NLR=N/L），N 的信息已被组合指标吸收，条件效应与边际效应方向相反（共线性/抑制效应）。简化曲线中 k=4 加入 N 后 AUC 不升反降（0.9783→0.9769）与此一致——这属于统计上可解释的现象，而非数据错误
