## 1. 建模问题定义与评价体系

### 1.1 任务与场景

- 二分类：流感 A 组（label=1）vs 健康组（label=0），n=528（476/52）
- **筛查场景**：假阴性代价高 → 阈值设定以"目标灵敏度 ≥ 0.90/0.95"为准，报告对应特异度

### 1.2 三性指标（题目要求的"分类效果、稳定性、可解释性"）

| 维度 | 指标 |
|---|---|
| 分类效果 | ROC-AUC、PR-AUC（9.15:1 不平衡下更敏感）、灵敏度@固定特异度 |
| 稳定性 | 重复 CV 的 AUC 均值±SD、特征被选中频率 |
| 可解释性 | OR+CI、判别得分、决策规则（三种语言） |

- **禁用准确率**作为主要指标（类别不平衡下误导）
- 校准：校准曲线 + Brier score（筛查工具必须校准良好）

---

## 2. 特征工程与选择（策略 B 阶段一：复用 Q1，不重复劳动）

### 2.1 特征池（来自问题 1 的综合证据表）

- **高潜力**：L、M、N
- **中潜力**：年龄、WBC、PLT、RDW
- **低潜力**：RBC、HB（不优先纳入）
- **组合指标**：NLR=N/L、MLR=M/L（取 log；注意 Q1 已记录的比值放大：L<0.3 共 11 例）

### 2.2 压缩规则（EPV 纪律）

- 健康组 52 例 → EPV=10 → **最终模型特征数 ≤ 5**
- 冗余处理：WBC-N（r=0.906）、RBC-HB（r=0.831）组内只选一个代表
- 变换口径：沿用 Q1 的 Box-Cox/log 结果

### 2.3 年龄策略

- 年龄为已知混杂（健康组中位 43 vs 流感组 31）→ **报告"含年龄"与"不含年龄"两个版本**，作为问题 3 推广分析的基础证据
- 特征选择一律在**嵌套 CV 内部**完成，严禁在 CV 外选特征

---

## 3. 模型体系与对比设计（策略 A + B + C 整合）

### 3.1 候选模型（3 正式 + 1 灵活对照 + 2 句稳健性）

| 模型 | 角色 | 解释语言 | 问题 3 接口 |
|---|---|---|---|
| **弹性网逻辑回归** | 主模型 | 系数/OR | 系数 → 评分卡 |
| **LDA** | 经典对照 | 判别得分 | 得分 → 阈值规则 |
| **CART（深 ≤3）** | 规则型对照 | if-then 规则 + 树状图 | **问题 3 简化方案候选** |
| SVM-RBF（灵活对照） | 非线性诊断 | — | 支撑"非线性无增益"结论 |

**主模型定案理由（策略 A）**：特征相关性强（WBC-N、RBC-HB）+ 样本小 → 弹性网是最稳的"带防过拟合保险的逻辑回归"。关键细节：阶段一已将特征压至 ≤5，弹性网的**作用是收缩稳系数（L2），而非再次选择（L1）**——α 固定（取 0.5），仅 λ 由嵌套 CV 确定。

### 3.2 统计裁决（策略 B 阶段三）

- 嵌套模型：似然比检验 / AIC-BIC
- 非嵌套：DeLong 检验比较 AUC
- 拟合优度：Hosmer-Lemeshow 检验 + 校准曲线

### 3.3 诊断论证（策略 C）

> 若 SVM-RBF/CART 在统一验证框架下未显著优于弹性网（DeLong 检验不显著且 AUC 差 <0.02），则证明线性可解释模型足够，无需引入非线性复杂度——与 Christodoulou 2019 综述结论一致。

### 3.4 补充（策略 D，一句话级）

- 三基模型按 CV Brier 倒数加权平均：性能与弹性网相当（AUC 差 <0.01），不改变推荐结论
- Firth 逻辑回归稳健性核验：比值特征可能引起准完全分离，报告"Firth 校正后系数方向与大小不变"一句

---

## 4. 统一验证框架（"避免过度依赖"的完整证据链）

1. **分层重复 k 折 CV**（5 折 × 10 次），报告均值 ± SD
2. **嵌套 CV**：特征选择/λ 调参在内部折完成（关键防线）
3. **Bootstrap 乐观度校正**（Efron，2000 次）：报告校正后 AUC——直接回答"对现有样本过度依赖"的担忧
4. **LOOCV 敏感性核验**（小样本保守口径）
5. 类不平衡：训练可用类别权重（注明），评价一律用灵敏度/特异度/PR-AUC

所有候选模型走同一框架，保证对比公平。

## 5. 模型对比与推荐

### 5.1 五维对比表

| 模型 | ROC-AUC（CV） | PR-AUC | Brier | 稳定性（SD） | 可解释性 |
|---|---|---|---|---|---|
| 弹性网逻辑回归 | | | | | 高（OR） |
| LDA | | | | | 高（得分） |
| CART（深≤3） | | | | | 高（规则） |
| SVM-RBF | | | | | 低 |

### 5.2 选择规则（预注册，避免事后挑选）

> 若简单模型与复杂模型判别力相当（AUC 差 <0.02）且校准、稳定性更优 → 选择简单可解释模型。
> 推荐逻辑：弹性网逻辑回归（主），LDA/CART 为对照，SVM 未显著胜出则作为"ML 无增益"的证据。

### 5.3 推荐叙述模板

"在统一嵌套 CV 框架下，弹性网逻辑回归的 AUC 为 X（95% CI），与 LDA/CART 相当、与 SVM 无显著差异（DeLong p>0.05）；其 Brier 最低、系数稳定、方向与问题 1 单变量分析一致（L 负、M/N 正）。按预注册规则推荐弹性网逻辑回归作为最终模型。"

## 7. 问题 3 衔接交付物（简化应用 + 推广评价角度）

### 7.1 简化曲线（1 张图）

- 横轴：特征数 k=1..5；纵轴：嵌套 CV AUC
- 特征按单变量 AUC 排序逐个加入（或 LASSO 路径）
- 用途：问题 3"少量指标能否保持判别能力"直接读曲线

### 7.2 评分卡基座（1 张表）

- 由推荐模型（弹性网）系数派生：连续变量分箱（按分位数 3-5 档）→ 每档整数分
- 总分阈值对应目标灵敏度
- 用途：问题 3 的简化方案主体（可手算、可审计）

### 7.3 筛查阈值与操作点

- 目标灵敏度 0.90 / 0.95 → 对应特异度、PPV、NPV（报告含年龄与不含年龄两个版本）

### 7.4 局限清单（供问题 3 推广分析引用）

| 限制来源 | 说明 |
|---|---|
| 样本量 | 健康组仅 52 例，效应量与 AUC 置信区间宽 |
| 类别比例 | 9.15:1，人为设定，不代表真实筛查患病率 |
| 谱系 | 仅"流感 A vs 健康"，不含其他呼吸道感染 |
| 年龄/性别 | 两组年龄结构错配（43 vs 31）；性别比例略有差异 |
| 比值放大 | MLR/NLR 高 AUC 部分来自 L 极小值，需交叉验证复核 |

## 9. 分析纪律

1. **预注册**：候选模型与选择规则在分析前定死，防止事后挑选
2. **统一框架**：所有模型同一嵌套 CV + Bootstrap 校正
