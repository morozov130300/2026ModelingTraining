# 问题二建模框架（碳感知调度）

> 依据：题目正文 + 附件1.docx + 数据实测核查（2026 问题一框架延续）
> 核心定位：问题一给出"纯算力 SLA 基准"；问题二引入电价、碳强度、可用新能源，任务执行区域与开工时刻成为决策变量，实现从"算力调度"到"能源调度"的升级。

---

## 0. 全局逻辑与关键数据事实

问题二的链条：任务放置 → AI IT 功率 → 区域 IT 负荷 → ×PUE 设施负荷 → 可再生/电网供电 → 电费与碳排放。

**必须先承认的三个数据事实**（决定模型形态）：

1. **时延按类型严格分档**：实时=20ms、批量=80ms、训练=150ms（全部任务精确一致）→ 三级柔性结构成立：
   - 实时：A/B/C 池内互调、D 仅本地、E↔F 互调（长距离被 20ms 排除）；
   - 批量：80ms 下几乎全连通，**仅 A→F、F→A 被 82ms 排除**；
   - 训练：150ms 下六区全连通。

2. **电价与碳强度区域同向**（corr=0.578）：A 最高（708 元/MWh、0.620 tCO2/MWh），E 最低（374、0.220），E 比 A 电价低 47.2%、碳强度低 64.5%。且**碳强度逐时变化**（每区域 138–152 个取值），配合峰/平/谷三档电价，构成"区域+时刻"联合优化的真实空间。

3. **可再生长期过剩**（关键风险点）：所有区域、所有小时 `AvailableRenewable(≥500MW) > 基准设施负荷(≤651MW)`。按附件 1 口径"可再生优先消纳、购电只补缺口"，**可再生优先后购电可趋近 0**——基准弃掉 775 万 MWh 可再生的同时购电 413 万 MWh（利用率仅 32.7%），是刻意不优的基准。

### 事实 3 的建模含义（论文必须诚实处理）
- 成本与碳排的大部分下降来自"可再生优先消纳"这一口径本身（相对浪费型基准），**而非任务迁移**；
- 任务调度的边际价值 = ① 避免负荷突破可再生包络（R<负荷）的高价/高碳小时，② 提升新能源利用率 KPI，③ 时刻与光伏/风电剖面匹配；
- **建议分层报告**：方案 A"可再生优先、不迁移"（对照）→ 方案 B"可再生优先 + 任务迁移/时刻优化"（本文方案）→ 量化迁移的**边际贡献**，而非把全部降幅归功于调度；
- 备选稳健化（若评委质疑"可再生免费无限可用"）：对可再生消纳设物理上限（如 ≤ 可用×α）或加利用成本做敏感性，展示结论不翻转。

## 1. 符号系统（延续问题一）

**任务/区域参数**：沿用 Q1——a_i、τ_i、g_i、d_i、σ_i、L_i、f_i；G_r、M_r、P_r、N_r(t)。

**新增能源参数**（region_time_data，0–2399 主时域；2400–2406 仅结清与结算）：
| 符号 | 含义 |
|---|---|
| ρ_r(t) | 购电价（元/MWh，峰/平/谷三档） |
| ξ_r(t) | 碳强度（tCO2/MWh，逐时变化） |
| R_r(t) | 可用新能源（MW） |
| φ_r(t) | 售电价（元/MWh；A/B/C=0，D/E/F>0） |
| S_r | 外送上限（MW；D=180、E=220、F=220，A/B/C=0） |

**决策变量**：x_{i,r}∈{0,1}（区域指派）、s_i∈ℤ（开工时刻），同 Q1。
**派生量**：o(i,t)（分钟级重叠，同 Q1）；AI_IT_Load(r,t)=Σ_i g_i·p_τ·o(i,t)·x_{i,r}；IT_Load=N_r(t)+AI_IT_Load；Total_Load=IT_Load×P_r。

## 2. 能源平衡与购买决策（Q2 无储能）

每小时每区域的平衡式（附件 1 口径，储能项=0）：

```
GridPurchase(r,t) + R_r(t) = Total_Load(r,t) + GridSell(r,t) + Curtailment(r,t)
```

最优解必然"可再生优先消纳"（免费且零碳）：

- 消纳 a(r,t) = min( R_r(t), Total_Load(r,t) )
- 购电 q(r,t) = max( 0, Total_Load(r,t) − R_r(t) )   ← 成本与碳排的唯一来源
- 富余时段（R>负荷）外送 y(r,t) ∈ [0, min(S_r, R_r(t)−Total_Load(r,t))]，取上限最优（售电收入为正）
- 弃电 w(r,t) = R_r(t) − a(r,t) − y(r,t)

成本与碳排（全时域累计，单位 1h）：
- 运行成本 C = Σ_{r,t} [ q(r,t)·ρ_r(t) − y(r,t)·φ_r(t) ]
- 碳排放 E = Σ_{r,t} q(r,t)·ξ_r(t)

**关键推论**：由事实 3，绝大多数时段 q≈0；调度优化的空间集中在"R<负荷"的少量小时（加 50MW AI 负荷后东区约 5–8% 小时紧张）——在这些小时选择"不突破包络"或"在低价低碳区突破"，就是问题二的边际收益来源。

## 3. 模型（决策变量 / 约束 / 目标）

### 3.1 决策变量
- x_{i,r}∈{0,1}、s_i∈ℤ（同 Q1）；
- 外送量 y(r,t)（由富余与 S_r 决定，可取解析最优，非核心变量）。

### 3.2 约束
| 编号 | 约束 | 说明 |
|---|---|---|
| C1 | Σ_r x_{i,r}=1 | 唯一性 |
| C2 | 实时任务 s_i=a_i 且 x_{i,σ_i}=1 | **固定本地**：SLA 最严解释 + 实时能耗占比仅 2.47%，优化价值可忽略（与 Q1 决策一致） |
| C3 | Σ_r D_{σ,r}·x_{i,r} ≤ L_i | 时延 SLA（预剪枝后候选集 R_i={r:D≤L_i}） |
| C4 | s_i+d_i ≤ f_i，s_i ≥ a_i | 完成时限（弹性任务） |
| C5 | Σ_i g_i·o(i,t)·x_{i,r} ≤ G_r | GPU 容量 |
| C6 | Σ_i g_i·p_τ·o(i,t)·x_{i,r} ≤ M_r−N_r(t) | IT 功率 |
| C7 | s_i+d_i ≤ 2406 | 不占第 2406 小时 |
| C8 | y(r,t) ≤ S_r，q(r,t) ≥ 0 | 购售电边界（外送上限） |

### 3.3 目标函数（碳价折算单目标 + 灵敏度）
```
min F(x,s) = C + λ·E
```
- λ 为碳价（元/tCO2），灵敏度旋钮：λ=0 纯经济，λ↑ 低碳导向；与问题四"碳约束场景"衔接；
- 因成本与碳排区域同向（corr=0.578），单目标即可覆盖主要权衡；论文补充 **ε-约束双目标**（min C s.t. E≤Ē）说明前沿形态——预期前沿较窄（区域同向），应如实呈现，不硬造丰富帕累托曲线。

## 4. 求解算法：两阶段分层（滚动时域作对照）

### 阶段一：区域指派（时间无关，粗粒度）
- 对每个弹性任务 i，计算候选区域 r∈R_i 的区域级吸引力：
  `score(i,r) = (ρ̄_r + λ·ξ̄_r)·g_i·p_τ·P_r·d_i`（平均能源成本折算，含 PUE）
- 约束：C3 剪枝 + 粗容量约束 `Σ_i g_i·d_i·x_{i,r} ≤ G_r·H_avail(r)`（H_avail 为区域可用小时数的松弛估计）+ C2（实时本地固定）；
- 求解：贪心按 score 升序指派，或最小费用流；规模 弹性任务 ~33k × 可达区域(≤6)，可控；
- 目的：给出初始指派，压缩阶段二搜索空间（**不追求精度**，阶段二会修正）。

### 阶段二：时刻选择 + 局部重指派（时间相关，精细）
- 按 EDF 排序处理任务；
- 对任务 i 在已指派区域（或候选集内按 score 排序的区域），枚举可行开工时刻 s∈[a_i, f_i−d_i]，用**边际能源成本**选优：
  `ΔC(s) = max(0, ρ_r(s)+λ·ξ_r(s) − 可再生免费用量余量) × g_i·p_τ·P_r·o(·)`，
  并做 GPU/IT 双容量检查（C5/C6）；
- 核心逻辑：优先填"可再生包络内"的免费时段，仅必要时在"突破包络"的高价/高碳小时安排，且优先安排在低价低碳区域；
- 后处理：对利用率峰值最高的区域做局部重定位（同 Q1 Step 4）。

### 对照方案：滚动时域
- 窗口 W≥72h（须大于最长任务 6.65h + 安全裕度），每次求解窗口内子问题（整数规划或贪心），仅提交窗口前 24h 决策，滚动推进；
- 论文报告两方案的 成本/碳排/利用率 与计算时间差异，说明两阶段法更接近全局解。

## 5. 评价指标（统一口径，与基准对比）

| 指标 | 口径 |
|---|---|
| 运行成本（元） | Σ(q·ρ) − Σ(y·φ) |
| 碳排放（tCO2） | Σ(q·ξ) |
| 网络时延（ms） | GPU-hour 加权平均与最大：Σ_i D_{σ,执行区}·g_i·d_i / Σ g_i·d_i |
| 新能源利用率 | (直接消纳+外送)/可用 = 1 − Σw/ΣR |

**对比体系（说明 3 要求统一口径重算）**：
1. 附件基准（region_time_data 的 NetGridImport、CarbonEmission、利用率）；
2. 问题一调度方案按本问口径重算（纯算力基准的能源后果）；
3. 方案 A：可再生优先、不迁移（隔离口径收益）；
4. 方案 B：本文方案（可再生优先+迁移+时刻优化）。
→ 用 3 与 4 的差量化**任务调度的边际贡献**，这是论文最有区分度的数字。
